## Welcome

Vercel gives you a single platform to build, deploy, and scale modern web applications. It combines AI Cloud capabilities, a global edge network, Fluid Compute, and Git-based deployments so you can move from code to production quickly.

Use this starter overview to understand the core pieces of the platform and decide where to go next.
