## Platform Releases

<Update label="2024-11-05" description="v2.3.0" tags={["feature", "bugfix"]}>

- Added edge function cold start metrics in the dashboard.
- Introduced support for custom domains with automatic SSL renewal.

## Bug Fixes

- Resolved CLI deployment timeout on large monorepos.
- Fixed API rate limit headers returning incorrect values.

</Update>

<Update label="2024-10-20" description="v2.2.1" tags={["bugfix"]}>
