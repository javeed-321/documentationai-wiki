## Recent updates

<Update label="2024-10-15" description="API version 2024-10-15" tags={["feature"]}>

- Added support for three new payment methods in the European Union.
- Introduced dashboard widgets for real-time revenue forecasting.

## API changes

- Updated the Payment Intents API to include expanded fraud signals.

</Update>

- Added bulk refund capability in the dashboard.

## Bug fixes

- Resolved an issue with webhook retry timing under high load.

</Update>
