<Update label="2026-06-01" description="v2026.06" tags={["feature", "bugfix"]}>

## New features

- Added support for a new payment method in select regions.
- Expanded availability for local payment acceptance in additional markets.
- Rolled out Dashboard improvements for subscription management workflows.

## Bug fixes

- Resolved an issue that could delay payment method display updates in the Dashboard.
- Fixed inconsistent API response formatting for certain billing objects.

## Deprecations

- Deprecated an older Dashboard export option. Migrate to the current export flow before removal.

</Update>

<Update label="2026-04-18" description="v2026.04" tags={["feature"]}>

## API version updates

- Introduced refinements to payment intent confirmation behavior.
- Added clearer validation messages for request payloads with missing required fields.
- Updated endpoint documentation for billing and Connect resources.

## Dashboard updates

- Improved navigation for revenue and reporting views.
- Added faster filtering for disputes and payout records.

</Update>

<Update label="2026-02-27" description="v2026.02" tags={["bugfix"]}>

## Fixes

- Fixed a case where some connected account settings did not save on the first attempt.
- Resolved a currency display issue for multi-currency price tables.
- Corrected a rare timeout during invoice preview generation.

## Notices

- Continue using the current API version unless you have tested newer behavior in staging.
- Review any webhook handlers that depend on older billing response fields.

</Update>

## What to expect

Stripe release notes typically include new payment methods and regions, API version changes, Dashboard updates, and deprecation notices. Check this page regularly if your integration depends on specific request or response behavior.

### How to read entries

- `feature` tags mark additions, improvements, and expanded availability.
- `bugfix` tags mark corrections to existing behavior.
- Dates use ISO format so you can track changes chronologically.
