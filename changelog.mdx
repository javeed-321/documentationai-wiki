## Voice

<Update label="2024-11-05" description="v2024-11-01" tags={["feature"]}>

- Added the `/Calls/{CallSid}/Transcriptions` endpoint for real-time call transcription.
- Introduced support for the 2024-11-01 API version with enhanced SIP trunking options.

</Update>

<Update label="2024-09-20" description="v2024-09-01" tags={["feature"]}>

- Launched new communication channel integrations for voice via WhatsApp voice calls.
- Expanded programmable voice parameters for conference bridging.

</Update>

<Update label="2024-08-10" description="v2024-08-01" tags={["breaking"]}>

- Removed deprecated TwiML `<Dial>` attributes; migrate to the new `recordingStatusCallback` parameter.
- Updated API versioning requirements for all Voice endpoints.

</Update>
