## Recent updates

<Update label="2026-06-12" description="v2.14.0" tags={["feature"]}>

- Added a new Conversations endpoint for retrieving persistent interaction context.
- Added a new Messaging endpoint for channel-specific delivery diagnostics.

## Deprecation guidance

Twilio marks older fields and routing options as deprecated before removing them. When you see a deprecation notice, confirm whether the replacement parameter changes behavior, default values, or validation rules.

Recommended migration steps:

1. Identify every request, webhook, and retry path that uses the deprecated field.
2. Replace the field with the supported parameter.
3. Test voice and messaging flows in a staging environment.
4. Monitor delivery and call logs after release.
5. Remove fallback logic only after the new path is stable.
