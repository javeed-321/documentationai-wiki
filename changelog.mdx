## Release Notes

<Update label="2024-10-15" description="v34.2.0" tags={["feature", "bugfix"]}>

## New Features
- Added automatic preview URL generation for monorepo projects.
- Introduced region selection for serverless functions in the dashboard.

## Bug Fixes
- Resolved CLI login failures on Windows arm64 systems.
- Fixed edge cache invalidation delays during deployments.

</Update>

<Update label="2024-09-28" description="v34.1.0" tags={["feature"]}>

## New Features
- Launched support for custom build timeouts up to 45 minutes.
- Enabled incremental static regeneration for dynamic routes.

</Update>

<Update label="2024-09-10" description="v34.0.0" tags={["breaking", "feature"]}>

## Breaking Changes
- Removed legacy Node.js 16 runtime support.

## New Features
- Added built-in analytics integration for all projects.

## Deprecations
- Deprecated the `--prod` flag in favor of environment-specific commands.

</Update>
