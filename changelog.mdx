## Release Notes

<Update label="2024-10-20" description="v2.4.0" tags={["feature"]}>

- Added POST `/v2/voice/calls` endpoint for direct call initiation.
- Updated SDK to version 3.2.1 with improved error handling.
- Expanded support to new EU regions with adjusted regional pricing.

</Update>

<Update label="2024-09-15" description="v2.3.1" tags={["bugfix"]}>

- Fixed billing calculation for multi-region voice calls.
- Resolved deprecation warnings for legacy `/v1/sms` endpoints.

</Update>

<Update label="2024-08-05" description="v2.3.0" tags={["feature"]}>

- Introduced new pricing tiers for high-volume API usage.
- Added GET `/v2/voice/regions` endpoint to query available regions.

</Update>
