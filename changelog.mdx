## Change categories

Stripe release notes usually include the following types of entries.

- API changes: request, response, and schema updates.
- New features: newly available platform capabilities.
- Deprecations: fields, endpoints, or behaviors scheduled for removal.
- Bug fixes: corrections to expected behavior or data display.
