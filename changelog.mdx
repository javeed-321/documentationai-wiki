## Release history

<Update label="2026-06-17" description="v3.14.0" tags={["feature"]}>

## New features

- Added Webflow AEO support for enterprise teams to improve visibility in AI search.
- Expanded AI-assisted content workflows for faster page and copy iteration.
- Improved Optimize workflows to help you test and refine high-intent pages.

## Platform improvements

- Updated discovery and guidance across AI-related tools.
- Refined publishing flow for teams managing multiple high-traffic sites.

</Update>

<Update label="2026-05-21" description="v3.13.0" tags={["feature", "bugfix"]}>

## CMS and hosting

- Improved CMS performance for large collections and frequent editorial updates.
- Reduced publishing delays for sites with complex content models.
- Added hosting reliability enhancements for steadier delivery during traffic spikes.

## Designer and collaboration

- Improved real-time collaboration clarity for shared editing sessions.
- Refined designer interactions to make layout adjustments more predictable.
- Fixed an issue that could cause comments to appear out of order in some projects.

</Update>

<Update label="2026-04-18" description="v3.12.0" tags={["feature"]}>

## Design and workflow updates

- Added new design tooling to speed up responsive page creation.
- Improved page building controls for structured landing page assembly.
- Enhanced shared libraries so teams can reuse approved components more consistently.

## Content operations

- Updated content editing flows to reduce friction for marketing teams.
- Improved localization support for multilingual site management.
- Streamlined handoff between design, content, and publishing tasks.

</Update>

## What changed in this release cycle

The latest releases center on visibility, performance, and team velocity. Webflow continues to expand AI features, strengthen CMS and hosting foundations, and refine the designer experience for collaborative website delivery.
