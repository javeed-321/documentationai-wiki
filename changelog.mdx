## Recent releases

<Update label="2024-10-15" description="v2.5.0" tags={["feature"]}>

## Checkout and variables

- Reduced average checkout time to under 3 seconds.
- Added support for `CART_TOKEN` and `PAYMENT_KEY` variables during order processing.
- Improved error handling for variable substitution.

</Update>

<Update label="2024-09-20" description="v2.4.0" tags={["feature"]}>

## Catalog scaling

- Increased supported catalog size to over 100000 products.
- Optimized database queries for large inventories.
- Added bulk import validation.

</Update>

<Update label="2024-08-10" description="v2.3.0" tags={["bugfix"]}>

## Performance fixes

- Fixed race condition in concurrent checkout sessions.
- Resolved memory leak under high product counts.

</Update>
