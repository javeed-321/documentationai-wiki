## Voice API Updates

<Update label="2024-11-05" description="2024.11" tags={["feature"]}>
## New Endpoints

- Added `POST /v1/Calls/{CallSid}/Recordings` to start on-demand recordings for active calls.
- Introduced `GET /v1/Conferences/{ConferenceSid}/Participants` with pagination support.

## API Version Changes

- Voice API now defaults to version `2024.11` for new accounts.
</Update>

<Update label="2024-09-18" description="2024.09" tags={["bugfix", "breaking"]}>
## Backward-Incompatible Updates

- Removed deprecated `StatusCallback` parameter from `POST /v1/Calls`. Use `StatusCallbackUrl` instead.
- Updated error response format for invalid TwiML to return HTTP 400 with structured JSON.

## Bug Fixes

- Fixed race condition in conference participant mute operations that caused inconsistent state.
</Update>

<Update label="2024-07-22" description="2024.07" tags={["feature"]}>
## New Feature Rollouts

- Launched real-time transcription for Voice calls via new `TranscriptionSid` resource.
- Added support for custom SIP headers on outbound calls.
</Update>
