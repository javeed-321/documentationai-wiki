## Recent releases

<Update label="2024-11-12" description="v0.148.0" tags={["feature"]}>

## New engine releases

- Released Neki engine preview for sharded Postgres with automated horizontal scaling.
- Added support for non-blocking schema changes on Vitess MySQL clusters.

</Update>

<Update label="2024-10-28" description="v0.147.2" tags={["improvement", "bugfix"]}>

## Performance and sharding improvements

- Increased NVMe IOPS limits by 40 percent on all managed clusters.
- Fixed an issue where large shard rebalances could temporarily reduce query throughput.

</Update>

<Update label="2024-10-05" description="v0.146.0" tags={["feature"]}>

## Console and CLI changes

- Added Database Traffic Control resource budgets in the web console.
- Introduced new `pscale db traffic` CLI commands for setting query limits.

</Update>
