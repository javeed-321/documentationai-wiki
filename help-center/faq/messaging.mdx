## Threads and reactions

<ExpandableGroup>
<Expandable title="How do I start a thread on a message?" default-open="true">

Click the thread icon under any message or hover and select Reply in thread. This keeps the conversation organized without cluttering the main channel.

</Expandable>
<Expandable title="Can I react to a message with an emoji?">

Yes. Hover over the message and click the smiley face icon, then pick any emoji. Reactions help show agreement or acknowledgment quickly.

</Expandable>
<Expandable title="Why can't others see my thread reply?">

Make sure you posted inside the thread, not the main channel. Check the thread count indicator on the original message to confirm replies are visible to channel members.

</Expandable>
</ExpandableGroup>

## Mentions and alerts

<ExpandableGroup>
<Expandable title="How do I mention someone so they get notified?" default-open="true">

Type the at symbol followed by their name or username. They receive an alert unless they have muted the channel or turned off notifications.

</Expandable>
<Expandable title="Why am I not getting alerts for mentions?">

Check your notification settings in Preferences. Ensure mentions are enabled for the channel and that Do Not Disturb is not active.

</Expandable>
<Expandable title="Can I mention an entire channel?">

Yes. Type at channel to notify everyone currently active in that channel. Use this sparingly to avoid unnecessary interruptions.

</Expandable>
</ExpandableGroup>

## File uploads

<ExpandableGroup>
<Expandable title="How do I share a file in a channel?" default-open="true">

Drag the file into the message box or click the paperclip icon to upload. The file appears for all members with access to that channel.

</Expandable>
<Expandable title="What file types can I upload?">

Slack supports most common formats including images, PDFs, and documents. Very large files may require a paid plan for extended storage.

</Expandable>
<Expandable title="Can I edit or replace an uploaded file?">

You can add a new version by uploading again and noting the update in the message. Original files stay in the history for reference.

</Expandable>
</ExpandableGroup>

## Channel privacy

<ExpandableGroup>
<Expandable title="How do I make a channel private?" default-open="true">

Create the channel and select the Private option during setup. Only invited members can join or view the content afterward.

</Expandable>
<Expandable title="Can I change a public channel to private later?">

No. Once created as public, a channel stays public. Create a new private channel and move important messages if needed.

</Expandable>
<Expandable title="Who can invite people to a private channel?">

Any current member can invite others. The channel creator does not hold special control after creation.

</Expandable>
</ExpandableGroup>
