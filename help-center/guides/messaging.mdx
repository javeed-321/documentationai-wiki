## Overview

When you need to communicate quickly in Slack, clear messages keep conversations moving. This guide walks you through formatting text, organizing replies in threads, adding reactions, and sharing files so you spend less time stuck and more time collaborating.

## Message Formatting

Slack supports simple markup that renders instantly. Use these shortcuts to emphasize key points without extra clicks.

- Wrap text in single asterisks for italics: `*important note*`
- Use double asterisks for bold: `**urgent update**`
- Add backticks for inline code: `` `command here` ``

You can combine styles in one line. Preview your message before sending to catch formatting errors.

## Threads and Replies

Threads keep side conversations from cluttering the main channel. Start a thread by hovering over any message and clicking the reply icon.

<Callout kind="tip">
  Reply in a thread when your comment applies to only one message. This helps teammates who join later follow the full context.
</Callout>

## Reactions and Emojis

Reactions let you acknowledge messages without typing. Click the smiley face under any message to add an emoji. Common reactions include thumbs-up for agreement or eyes for "looking into this."

<Tabs>
  <Tab title="Desktop" icon="monitor">
    Right-click a message and select Add reaction, then browse or search the emoji picker.
  </Tab>
  <Tab title="Mobile" icon="smartphone">
    Long-press the message and tap the reaction button at the bottom of the screen.
  </Tab>
</Tabs>

## File Sharing

Share documents, images, or screenshots directly in a conversation. Drag a file into the message box or click the paperclip icon.

<Expandable title="Supported file types" default-open="false">
  Slack accepts PDFs, images, spreadsheets, and most common document formats up to 1 GB per file.
</Expandable>

## Best Practices

- Keep messages short and specific so readers grasp the point in seconds.
- Use threads for follow-ups longer than two sentences.
- Add reactions instead of short replies like "thanks" to reduce notification noise.
- Name files clearly before uploading so teammates know what they contain at a glance.

If a message still feels unclear after formatting, rewrite it rather than adding more markup.
