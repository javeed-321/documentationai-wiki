## Common issues

We know these problems can block your readers. Each expandable below walks through a specific symptom, its usual cause, and the exact steps to fix it.

<Expandable title="Widget not appearing on your site" default-open="false">
The Intercom widget fails to load on any page even after you embed the snippet.

**Cause**  
The install code is missing from the `<head>` section or the site blocks the Intercom domain.

**Fix**  
1. Open your site HTML and confirm this line sits inside `<head>`:  
   ```html
   <script src="https://widget.intercom.io/widget/YOUR_APP_ID"></script>
   ```
2. Replace `YOUR_APP_ID` with the ID shown on the Intercom dashboard under Settings → Installation.
3. Clear your browser cache and reload the page. If the widget still does not appear, add `*.intercom.io` to your content security policy.
</Expandable>

<Expandable title="Search returns no results" default-open="false">
Visitors type a query in the Help Center search bar but receive an empty list and the message "No articles found."

**Cause**  
Articles exist but are not indexed because they are unpublished or lack search keywords.

**Fix**  
1. Go to Content → Articles and open each article.
2. Check that the status shows "Published" and the article is added to a public collection.
3. Add at least three relevant keywords in the article settings.
4. Wait up to five minutes, then test the search again on your Help Center at `https://example.com/help`.
</Expandable>

<Expandable title="Articles not visible in a collection" default-open="false">
A collection page shows fewer articles than you expect, or some articles are missing entirely.

**Cause**  
The articles are not assigned to the collection or the collection itself is set to private.

**Fix**  
1. Edit the collection and confirm its visibility is set to "Public."
2. On each missing article, click "Add to collection" and select the correct collection.
3. Save and refresh the collection URL. The article count should update immediately.
</Expandable>

<Expandable title="Custom styling does not apply" default-open="false">
Changes to colors, fonts, or layout in the Help Center theme editor have no effect on the live site.

**Cause**  
The custom CSS file is not linked or contains a syntax error that prevents loading.

**Fix**  
1. In Settings → Appearance, verify the CSS URL points to a valid file on your server.
2. Open the CSS file and wrap any new rules inside the `.intercom-help-center` selector.
3. Run a CSS validator on the file to catch missing semicolons or braces.
4. Clear the Intercom cache from Settings → Advanced and reload your Help Center.

</Expandable>
