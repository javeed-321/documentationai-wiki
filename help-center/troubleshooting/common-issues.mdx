## Common Issues

If something feels off in your Help Center, start here. Each section walks through a real symptom, why it happens, and the quickest fix.

<Expandable title="Search returns no results or outdated articles" default-open="false">
Problem: Visitors type a query and see "No articles found" even though matching content exists.

Cause: The search index has not updated after recent article changes or the index job failed.

Fix: Go to Guide admin, open Settings, and click Rebuild search index. Wait five minutes, then test the same query again. If the problem continues, check the Activity log for an entry that reads "Search index update failed".
</Expandable>

<Expandable title="Published article does not appear on the site" default-open="false">
Problem: You click Publish but the article stays hidden from end users.

Cause: The article is still in draft status, or its section permission is set to Agents only.

Fix: Open the article, confirm the status shows Published, then click the section name and set Permissions to Everyone. Save and refresh the Help Center URL.
</Expandable>

<Expandable title="Users see a permission error when signing in" default-open="false">
Problem: End users receive the message "You do not have permission to view this page" right after login.

Cause: The user role lacks access to the Help Center or the SSO mapping is incorrect.

Fix: In Support admin, go to People, find the user, and change Role to End User. Then verify the SSO settings under Channels, Help Center, Authentication and confirm the external ID field matches the value sent by your identity provider.
</Expandable>

<Expandable title="Custom theme or widget fails to load" default-open="false">
Problem: The Help Center shows the default theme instead of your branded one, or the contact widget never appears.

Cause: The theme file contains a syntax error or the widget script tag is missing from the layout.

Fix: In Guide, open the active theme, click Preview, and fix any red error lines shown in the editor. For the widget, edit the document_head.hbs file and add the script tag exactly as provided in the widget setup screen, then publish the theme.
</Expandable>

<Expandable title="Articles do not sync from Support to Help Center" default-open="false">
Problem: New or updated articles created in Support never show up in the Help Center.

Cause: The sync job between Support and Guide is paused or the integration token has expired.

Fix: Go to Admin, Channels, Help Center, Integrations and click Reconnect next to Support. Enter a fresh API token if prompted. Once connected, manually trigger a sync by clicking Sync now and watch the Activity log for a "Sync completed" entry.
</Expandable>
