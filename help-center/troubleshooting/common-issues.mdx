## Payment and Refund Failures

<Expandable title="Payment declined with message 'Your payment was declined. Please try another card.'" default-open="false">

**Problem**  
Customers see this exact error during checkout and the order does not complete.

**Cause**  
The card issuer rejected the transaction, often due to mismatched billing address, insufficient funds, or regional restrictions on the merchant account.

**Fix**  
1. Ask the customer to confirm the billing address matches the card exactly.  
2. Have them try a different payment method.  
3. In Shopify admin, go to Settings > Payments and verify your payout account is active.  
4. If the issue persists for many customers, contact Shopify Support with the order number.

</Expandable>

<Expandable title="Refund fails with 'Refund could not be processed at this time'" default-open="false">

**Problem**  
You attempt a refund but receive the failure message and the amount stays on the order.

**Cause**  
The original payment processor has not yet settled the funds or a daily refund limit has been reached.

**Fix**  
1. Wait 24 hours after the original transaction and try again.  
2. Check Settings > Payments for any processor alerts.  
3. Issue a manual refund through your payment provider dashboard if needed, then mark the order as refunded in Shopify.

</Expandable>

## Checkout and Cart Issues

<Expandable title="Cart shows 'Item unavailable' even though the product is in stock" default-open="false">

**Problem**  
Products appear in the cart but cannot be purchased, blocking checkout.

**Cause**  
A recent inventory sync or location change marked the item as unavailable at the selected shipping location.

**Fix**  
1. Open the product in Shopify admin and confirm inventory is tracked at the correct location.  
2. Clear the customer's browser cache or ask them to try an incognito window.  
3. Disable any third-party inventory apps temporarily to test.

</Expandable>

<Expandable title="Checkout button does nothing or shows a blank screen" default-open="false">

**Problem**  
Clicking "Check out" produces no response or a blank page.

**Cause**  
A script conflict from an installed app or an outdated theme file is preventing the checkout script from loading.

**Fix**  
1. In the theme editor, click Actions > Edit code and search for recent app script tags.  
2. Remove or comment out any custom checkout scripts added in the last week.  
3. Test checkout in a default theme to isolate the issue.

</Expandable>

## App and Integration Conflicts

<Expandable title="App fails to load with 'This app could not be loaded'" default-open="false">

**Problem**  
An installed app shows the error on the dashboard or product pages.

**Cause**  
The app's OAuth token has expired or the app is not compatible with your current Shopify plan.

**Fix**  
1. Go to Settings > Apps and sales channels, then reinstall the app.  
2. Check the app's status page for any reported outages.  
3. Contact the app developer with the exact error text and your shop domain.

</Expandable>

## Theme and Mobile Display Problems

<Expandable title="Product images overlap text on mobile devices only" default-open="false">

**Problem**  
The site looks fine on desktop but images cover text when viewed on phones.

**Cause**  
A theme CSS rule lacks a responsive breakpoint for smaller viewports.

**Fix**  
1. In the theme editor, open the code editor and locate the image container class.  
2. Add or adjust a media query such as `@media screen and (max-width: 768px)`.  
3. Preview changes on multiple devices before publishing.

</Expandable>

<Expandable title="Navigation menu disappears or collapses incorrectly on mobile" default-open="false">

**Problem**  
The hamburger menu fails to expand or links are hidden on phones and tablets.

**Cause**  
JavaScript for the mobile menu is blocked by another script or a custom theme modification.

**Fix**  
1. Temporarily switch to the default Dawn theme and test the menu.  
2. Re-add your custom code one section at a time to find the conflict.  
3. Ensure any custom JavaScript is wrapped in a `DOMContentLoaded` listener.

</Expandable>

<Callout kind="tip">
If none of these steps resolve your issue, collect the exact error message and steps to reproduce, then reach out to Shopify Support from the Help section in your admin.
</Callout>
