## Prerequisites

<Callout kind="info">
You need an active ShopifyMax account and an API key before proceeding. Checkout completes in under three seconds and supports stores with more than 100000 products.
</Callout>

## Store Setup

<Steps>
  <Step title="Create your store" icon="plus-circle">
    Log in to the dashboard and select Create Store. Enter your store name and select the high-speed checkout template.
  </Step>
  <Step title="Configure domain" icon="globe">
    Add your custom domain in the settings panel. ShopifyMax automatically provisions a secure certificate.
  </Step>
  <Step title="Connect catalog" icon="database">
    Import your product catalog. The platform indexes more than 100000 products in under two minutes.
  </Step>
</Steps>

## Variable Integration

Connect your checkout flow to the required variables for cart and payment handling.

<CodeGroup tabs="JavaScript,Python">
```javascript
const checkout = new ShopifyMax.Checkout({
  cartToken: process.env.CART_TOKEN,
  paymentKey: process.env.PAYMENT_KEY,
});

checkout.launch();
```
```python
import shopifymax

client = shopifymax.Client(
    cart_token=os.environ["CART_TOKEN"],
    payment_key=os.environ["PAYMENT_KEY"],
)

client.launch_checkout()
```
</CodeGroup>

## Initial Deployment
