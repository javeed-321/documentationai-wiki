## Prerequisites

<Callout kind="info">
  You need a GitHub, GitLab, or Bitbucket account and a project with a `package.json` or static files ready to deploy.
</Callout>

## Set up the Vercel CLI

<Steps>
  <Step title="Install the CLI" icon="download">
    Run the following command to add the Vercel command-line tool to your system.

    ```bash
    npm install -g vercel
    ```
  </Step>
  <Step title="Log in" icon="log-in">
    Authenticate with your Vercel account.

    ```bash
    vercel login
    ```
  </Step>
</Steps>

## Deploy with Git

Connect your repository for automatic deployments on every push.

<CodeGroup tabs="Terminal,GitHub">
```bash
vercel
```
```bash
# Push to your connected repository
git push
```
</CodeGroup>

Vercel detects your framework, builds the project, and creates a unique preview URL for every branch.

## Preview environments

Every pull request receives its own isolated preview deployment. Share the link with teammates for instant feedback before changes reach production.

## Promote to production

Merge the pull request to trigger a production deployment. Use the dashboard to promote any preview to production with a single click when you are ready.
