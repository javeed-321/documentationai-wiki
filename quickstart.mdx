## Prerequisites

<Callout kind="info">
  You need Node.js 18 or later and a Trigger.dev account. Sign up at example.com if you have not already.
</Callout>

## Install the SDK

<Steps>
  <Step title="Create a project" icon="folder-plus">
    Run the following command to scaffold a new Trigger.dev project:

    ```bash
    npx create-trigger@latest my-project
    cd my-project
    ```
  </Step>
  <Step title="Install dependencies" icon="download">
    Add the Trigger.dev SDK to your project:

    ```bash
    npm install @trigger.dev/sdk
    ```
  </Step>
</Steps>

## Define your first task

<CodeGroup tabs="TypeScript">
```typescript
import { task } from "@trigger.dev/sdk/v3";

export const helloWorld = task({
  id: "hello-world",
  run: async (payload: { name: string }) => {
    return `Hello, ${payload.name}!`;
  },
});
```
</CodeGroup>

## Run locally

<Steps>
  <Step title="Start the dev server" icon="play">
    Launch the Trigger.dev development server:

    ```bash
    npx trigger dev
    ```
  </Step>
  <Step title="Trigger the task" icon="send">
    Use the dashboard or CLI to run your task with a payload. The task executes and streams logs in real time.
  </Step>
</Steps>

## Deploy to Trigger.dev

<Steps>
  <Step title="Deploy your tasks" icon="rocket">
    Push your tasks to the Trigger.dev platform:

    ```bash
    npx trigger deploy
    ```
  </Step>
</Steps>
