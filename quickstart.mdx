## Prerequisites

<Callout kind="info">

Create a free account at the PlanetScale dashboard and install the CLI before you begin.

</Callout>

## Create a database

<Tabs>
  <Tab title="Vitess" icon="database">
    <Steps>
      <Step title="Log in to the dashboard">
        Open the dashboard and click Create database.

      </Step>
      <Step title="Choose Vitess">
        Select Vitess, name the database, and pick a region.

      </Step>
      <Step title="Create the database">
        Click Create. PlanetScale provisions the cluster in under a minute.

      </Step>
    </Steps>
  </Tab>
  <Tab title="Postgres" icon="database">
    <Steps>
      <Step title="Log in to the dashboard">
        Open the dashboard and click Create database.

      </Step>
      <Step title="Choose Postgres">
        Select Postgres with the Neki engine and name the database.

      </Step>
      <Step title="Create the database">
        Click Create. The sharded Postgres instance is ready shortly.

      </Step>
    </Steps>
  </Tab>
</Tabs>

## Connect your application

<CodeGroup tabs="Node.js,Python">
```javascript
const mysql = require('mysql2');
const connection = mysql.createConnection({
  host: 'host.example.com',
  user: 'user',
  password: 'YOUR_PASSWORD',
  database: 'your_database',
});
connection.connect();
```
```python
import psycopg
conn = psycopg.connect(
    host="host.example.com",
    user="user",
    password="YOUR_PASSWORD",
    dbname="your_database"
)
```
</CodeGroup>

## Import a schema

<Steps>
  <Step title="Prepare your schema file">
    Save your CREATE TABLE statements to schema.sql.

  </Step>
  <Step title="Apply with the CLI">
    Run the following command from your project directory.

```bash
pscale database import-schema your_database schema.sql
```

  </Step>
</Steps>
