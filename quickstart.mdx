## Quickstart

Stripe helps you accept payments quickly, test safely, and expand into billing, subscriptions, and financial services later. This guide gets you to your first successful payment in under five minutes.

<Callout kind="info">

You need a Stripe account before you can use the API. Start in test mode so you can create and verify a payment without moving real money.

</Callout>

## Before you begin

Make sure you have a Stripe account, access to the Dashboard, and a way to run a simple server or script. You will also need your publishable key and secret key from the API keys page.

If you are evaluating Stripe, test mode is the best place to start. It lets you create payments with test cards, inspect events, and confirm your integration before you switch to live mode.

<Steps>
  <Step title="Create your account" icon="users">
    Sign up for Stripe and open the Dashboard.

    - Go to the registration page
    - Complete your business details
    - Confirm your email address

  </Step>
  <Step title="Find your API keys" icon="lock">
    Open the API keys page in the Dashboard and copy the keys for test mode.

    - Use the publishable key on the client side
    - Use the secret key on the server side
    - Keep the secret key private

  </Step>
  <Step title="Turn on test mode" icon="shield">
    Work in test mode while you build and verify your first payment.

    - Confirm the Dashboard shows test data
    - Use test cards only
    - Review events and payment status in the Dashboard

  </Step>
  <Step title="Create your first payment" icon="zap">
    Send a payment request from your server and confirm it in the Dashboard.

    - Create a payment intent
    - Confirm the payment
    - Check that the payment succeeds in test mode

  </Step>
</Steps>

## Minimal example

Use this minimal flow to confirm that your account, keys, and test mode are configured correctly. Replace the placeholder values with your own key from the Dashboard.

<CodeGroup tabs="JavaScript,cURL">
  ```javascript
const response = await fetch("https://api.example.com/v1/payments", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_SECRET_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    amount: 500,
    currency: "usd",
    payment_method: "pm_card_visa"
  })
});

const data = await response.json();
console.log(data);
  ```
  ```bash
curl https://api.example.com/v1/payments \
  -H "Authorization: Bearer YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 500,
    "currency": "usd",
    "payment_method": "pm_card_visa"
  }'
  ```
</CodeGroup>

## What to check in the Dashboard

After you run your first request, confirm three things in the Dashboard: the payment appears in test mode, the amount and currency are correct, and the status matches the result you expected.

If the payment fails, verify that you copied the secret key from test mode and that your request uses a supported test payment method. If it succeeds, you are ready to move on to payment optimization, billing, or subscriptions.

## Common next steps

Once your first payment works, you usually do three things: review payment events, switch from test mode to live mode, and add error handling for failed or incomplete payments.

<Expandable title="Troubleshooting" default-open="false">

Check these items if your first request does not succeed:

- Confirm you are using a test key in test mode
- Verify the request body includes a valid amount and currency
- Make sure you are using a supported test payment method
- Review the payment status in the Dashboard for details

</Expandable>
