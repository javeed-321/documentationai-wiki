## Prerequisites

<Callout kind="info">
  You need a PlanetScale account. Sign up at `https://example.com` if you do not already have one. No credit card is required to start.
</Callout>

## Create your first database

Follow these steps to provision a database in under two minutes.

<Steps>
  <Step title="Sign in to the dashboard" icon="log-in">
    Open the PlanetScale dashboard and select **Create database**.
  </Step>
  <Step title="Name the database" icon="edit">
    Enter a name such as `quickstart-db` and choose a region close to your application.
  </Step>
  <Step title="Create the database" icon="check-circle">
    Click **Create**. PlanetScale provisions a production-ready MySQL instance instantly.
  </Step>
</Steps>

## Install the PlanetScale CLI

<Steps>
  <Step title="Install the CLI" icon="download">
    Run the installation command for your operating system.

    ```bash
    brew install pscale
    ```
  </Step>
  <Step title="Authenticate" icon="key">
    Log in with your PlanetScale credentials.

    ```bash
    pscale auth login
    ```
  </Step>
</Steps>

## Connect an application

Use the following connection string format with any MySQL client. Replace the placeholders with values from your database settings page.

<CodeGroup tabs="Node.js,Python,Go">
```javascript
const mysql = require('mysql2');
const connection = mysql.createConnection({
  host: 'aws.connect.psdb.cloud',
  user: 'your_username',
  password: 'your_password',
  database: 'quickstart-db',
  ssl: { rejectUnauthorized: true }
});
```
```python
import mysql.connector

connection = mysql.connector.connect(
    host="aws.connect.psdb.cloud",
    user="your_username",
    password="your_password",
    database="quickstart-db",
    ssl_ca="/path/to/ca.pem"
)
```
```go
import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

dsn := "your_username:your_password@tcp(aws.connect.psdb.cloud:3306)/quickstart-db?tls=true"
db, err := sql.Open("mysql", dsn)
```
</CodeGroup>

## Branching workflow

PlanetScale uses branches for safe schema changes. Create a development branch, apply changes, then promote them.

```bash
pscale branch create quickstart-db dev
pscale connect quickstart-db dev
```

Run your migration on the `dev` branch, then open a deploy request from the dashboard to merge changes into the main branch.
