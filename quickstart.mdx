## Quickstart

Set up Stripe, create your first payment intent, and confirm it with a test card. This starter path assumes you are evaluating Stripe for the first time and want a fast, working result.

Stripe gives you the building blocks to accept payments, manage billing, and grow into more advanced revenue models later. In this guide, you focus on the minimum path to success: account setup, API keys, installation, a payment intent, and a test payment.

<Callout kind="info">
Use your Stripe test mode keys while you build. Test mode lets you validate your integration safely before you accept real payments.
</Callout>

### What you will do

You will complete four small steps:

- Create a Stripe account and find your API keys.
- Install a Stripe library in your app.
- Create a payment intent on your server.
- Confirm the payment with a test card.

### Before you start

Make sure you have:

- A Stripe account.
- A server environment where you can keep secret keys private.
- A client app or simple frontend that can send the payment details.
- Access to Stripe test mode.

## Set up your account and keys

Start in the Stripe Dashboard and switch to test mode. From there, copy your publishable key for the client and your secret key for the server. Keep the secret key out of browser code and version control.

If you are just exploring, you can use the dashboard links to move between account creation, sign in, and guided setup. Once your account is ready, you can reuse the same test-mode keys while you build the rest of the flow.

<Steps>
  <Step title="Create or open your account" icon="users">
    Go to the Stripe Dashboard and sign in or create a new account.

    Use the account you plan to keep for development so your test data stays in one place.

  </Step>
  <Step title="Find your test keys" icon="key">
    Open the Developers area in the dashboard and copy:

    - Your publishable key for client-side use.
    - Your secret key for server-side use.

    Store the secret key as an environment variable, not in your frontend bundle.

  </Step>
  <Step title="Prepare your environment" icon="settings">
    Add the key values to your local environment and restart your app so the values load correctly.

    Keep test mode enabled until you are ready to move to live payments.

  </Step>
</Steps>

## Install Stripe libraries

Install the Stripe library that matches your server language. The library helps you create payment intents securely from your backend.

<CodeGroup tabs="JavaScript,Python,cURL">
  ```javascript
  import Stripe from "stripe";

  const stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

  export async function createPaymentIntent() {
    const paymentIntent = await stripe.paymentIntents.create({
      amount: 2000,
      currency: "usd",
      automatic_payment_methods: {
        enabled: true,
      },
    });

    return paymentIntent.client_secret;
  }
  ```

  ```python
  import os
  import stripe

  stripe.api_key = os.environ["STRIPE_SECRET_KEY"]

  def create_payment_intent():
      payment_intent = stripe.PaymentIntent.create(
          amount=2000,
          currency="usd",
          automatic_payment_methods={"enabled": True},
      )
      return payment_intent.client_secret
  ```

  ```bash
  curl https://api.example.com/create-payment-intent \
    -H "Content-Type: application/json" \
    -d '{"amount":2000,"currency":"usd"}'
  ```
</CodeGroup>

Stripe libraries handle the API calls for you and keep your integration predictable as you grow. For this quickstart, you only need enough code to create one payment intent and return its client secret to the browser.

## Create your first payment intent

A payment intent tells Stripe how much to charge and in which currency. Your server creates it, then your client uses the returned client secret to complete the payment.

Here is a minimal server route that creates a payment intent for a twenty-dollar charge in U.S. dollars.

<CodeGroup tabs="Node.js,Python">
  ```javascript
  import express from "express";
  import Stripe from "stripe";

  const app = express();
  app.use(express.json());

  const stripe = new Stripe(process.env.STRIPE_SECRET_KEY);

  app.post("/create-payment-intent", async (req, res) => {
    const paymentIntent = await stripe.paymentIntents.create({
      amount: 2000,
      currency: "usd",
      automatic_payment_methods: {
        enabled: true,
      },
    });

    res.json({
      clientSecret: paymentIntent.client_secret,
    });
  });

  app.listen(3000);
  ```

  ```python
  from flask import Flask, jsonify
  import os
  import stripe

  app = Flask(__name__)
  stripe.api_key = os.environ["STRIPE_SECRET_KEY"]

  @app.post("/create-payment-intent")
  def create_payment_intent():
      payment_intent = stripe.PaymentIntent.create(
          amount=2000,
          currency="usd",
          automatic_payment_methods={"enabled": True},
      )

      return jsonify(clientSecret=payment_intent.client_secret)

  app.run(port=3000)
  ```
</CodeGroup>

When you create the intent, you define the amount and currency on the server. Stripe returns a client secret that your frontend uses to complete the payment without exposing your secret key.

## Test with a card

Use Stripe test cards to confirm the end-to-end flow. A successful test shows that your server, client, and Stripe account are connected correctly.

<Steps>
  <Step title="Send the client secret to your frontend" icon="arrow-right">
    Call your server route from the browser and store the returned client secret.

    Use that value to confirm the payment on the client.

  </Step>
  <Step title="Enter a test card" icon="credit-card">
    Use a Stripe test card number such as `4242 4242 4242 4242`.

    Enter any future expiration date, any three-digit CVC, and any postal code.

  </Step>
  <Step title="Confirm the payment" icon="check-circle">
    Confirm the payment and wait for the success response.

    If the payment succeeds, you have completed your first Stripe transaction in test mode.

  </Step>
</Steps>

### Common test result

If the payment succeeds, you should see a completed payment in the dashboard test data view. If it fails, verify that:

- Your secret key is the test mode secret key.
- Your server creates the payment intent before the client confirms it.
- The amount is a valid integer value in the smallest currency unit.
