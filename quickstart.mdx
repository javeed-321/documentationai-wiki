## Prerequisites

<Callout kind="info">
You need a Vercel account and Node.js version 18 or later on your machine.
</Callout>

## Install the Vercel CLI

<Steps>
<Step title="Install globally" icon="download">
Run the following command to add the CLI to your system.

```bash
npm install -g vercel
```
</Step>
<Step title="Log in" icon="log-in">
Authenticate with your account.

```bash
vercel login
```
</Step>
</Steps>

## Deploy from the command line

<CodeGroup tabs="npm,yarn">
```bash
vercel
```
```bash
yarn dlx vercel
```
</CodeGroup>

Follow the prompts to select your project and confirm the deployment. Your site becomes live immediately at a generated URL.

## Connect a Git repository

Push your code to GitHub, GitLab, or Bitbucket, then import the repository from the Vercel dashboard. Every push to the main branch triggers an automatic build and deploy.

## Automatic builds and deploys

Vercel detects your framework, installs dependencies, and runs the build script. Production deployments appear at your assigned domain while preview deployments are created for every pull request.

## Add a custom domain

Navigate to your project settings and enter a domain from example.com. Vercel provisions an SSL certificate automatically and routes traffic within minutes.
