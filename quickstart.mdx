## Prerequisites

<Callout kind="info">
Before you begin, create a ShopifyMax account at `https://example.com` and note your store domain. You need Node.js 18 or later installed.
</Callout>

## Initial Store Configuration

Follow these steps to launch your store with optimized checkout.

<Steps>
  <Step title="Create the store" icon="plus">
    Log in to the dashboard and select Create Store. Name it and choose your product catalog size.
  </Step>
  <Step title="Set performance options" icon="zap">
    Enable sub-three-second checkout in the Performance tab. ShopifyMax automatically handles catalogs exceeding 100000 products.
  </Step>
</Steps>

## Enable CART_TOKEN and PAYMENT_KEY

Configure the required variables for cart and payment flows.

<Steps>
  <Step title="Add CART_TOKEN" icon="key">
    Navigate to Settings then Variables. Create a new entry named `CART_TOKEN` and paste your generated token value.
  </Step>
  <Step title="Add PAYMENT_KEY" icon="lock">
    In the same section, add `PAYMENT_KEY` with your payment provider key. Save and publish the configuration.
  </Step>
</Steps>

## Minimal Working Example

Use this configuration to verify your setup.

<CodeGroup tabs="JavaScript,CLI">
```javascript
import { ShopifyMax } from 'shopifymax';

const client = new ShopifyMax({
  store: 'your-store.example.com',
  cartToken: process.env.CART_TOKEN,
  paymentKey: process.env.PAYMENT_KEY,
});

await client.checkout.create({ productId: 'demo-product' });
```
```bash
npm install -g shopifymax-cli
shopifymax init my-store
shopifymax deploy --env production
```
</CodeGroup>
