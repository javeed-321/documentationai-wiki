## Overview

Every request to the Twilio REST API must include valid credentials. You authenticate using HTTP Basic Auth with your Account SID as the username and either your Auth Token or an API key secret as the password. All requests must use HTTPS.

## Authentication Methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">
    <ParamField body="AccountSid" param-type="string" required="true">
      Your unique 34-character Account SID begins with `AC`. Find it in the Twilio Console under Account Info.
    </ParamField>
    <ParamField body="AuthToken" param-type="string" required="true">
      The 32-character Auth Token associated with the Account SID. Treat it like a password and rotate it periodically.
    </ParamField>
  </Tab>
  <Tab title="API Keys" icon="key">
    <ParamField body="ApiKeySid" param-type="string" required="true">
      The 34-character API key SID begins with `SK`. Create keys in the Twilio Console under API Keys.
    </ParamField>
    <ParamField body="ApiKeySecret" param-type="string" required="true">
      The 32-character secret paired with the API key SID. Store it securely and rotate keys on a schedule.
    </ParamField>
    <Callout kind="info">
      API keys support granular permissions and can be revoked independently of your main Auth Token.
    </Callout>
  </Tab>
</Tabs>

## Sending Authenticated Requests

Use the credentials in the Authorization header formatted as Basic base64-encoded `username:password`.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/2010-04-01/Accounts \
  -u "ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx:your_auth_token_or_secret"
```
```python
import requests
from requests.auth import HTTPBasicAuth

response = requests.get(
    "https://api.example.com/2010-04-01/Accounts",
    auth=HTTPBasicAuth("ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", "your_auth_token_or_secret")
)
print(response.json())
```
```javascript
const response = await fetch("https://api.example.com/2010-04-01/Accounts", {
  headers: {
    Authorization: "Basic " + Buffer.from(
      "ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx:your_auth_token_or_secret"
    ).toString("base64"),
  },
});
const data = await response.json();
console.log(data);
```
</CodeGroup>

## Security Best Practices

<Callout kind="alert">
  Never commit Account SIDs, Auth Tokens, or API key secrets to source control. Use environment variables or a secrets manager. Rotate credentials at least every 90 days and immediately revoke any key that may have been exposed.
</Callout>
