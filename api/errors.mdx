## HTTP Status Codes

Twilio returns standard HTTP status codes for all REST API responses. Review the status code first to determine the category of the error, then inspect the response body for the specific Twilio error code and message.

- `400 Bad Request` indicates malformed syntax or invalid parameters in the request.
- `401 Unauthorized` occurs when authentication credentials are missing or invalid.
- `404 Not Found` signals that the requested resource does not exist.
- `429 Too Many Requests` appears when you exceed the allowed request rate.

## Twilio Error Codes

Twilio returns a JSON body with `code`, `message`, and `more_info` fields on error responses. The numeric code identifies the exact failure. Use the code to locate the matching expandable section below.

<Expandable title="Error 21211: Invalid 'To' Phone Number" default-open="false">
**Problem**

You receive HTTP 400 and the following response body:

```json
{
  "code": 21211,
  "message": "The 'To' phone number is not a valid phone number.",
  "more_info": "https://www.twilio.com/docs/errors/21211"
}
```

**Cause**

The `To` parameter contains a value that Twilio cannot parse as an E.164 phone number.

**Fix**

Supply the `To` value in E.164 format, including the leading plus sign and country code. Example request:

```bash
curl -X POST https://api.example.com/2010-04-01/Accounts/ACxxxxxxxx/Messages.json \
  -u "ACxxxxxxxx:YOUR_AUTH_TOKEN" \
  --data-urlencode "To=+15551234567" \
  --data-urlencode "From=+15559876543" \
  --data-urlencode "Body=Test message"
```
</Expandable>

<Expandable title="Error 20003: Authentication Error" default-open="false">
**Problem**

You receive HTTP 401 and the following response body:

```json
{
  "code": 20003,
  "message": "Authenticate",
  "more_info": "https://www.twilio.com/docs/errors/20003"
}
```

**Cause**

The request lacks a valid Account SID and Auth Token pair or uses an invalid API key.

**Fix**

Include the correct credentials in the Authorization header. Use your Account SID as the username and your Auth Token as the password. Verify the SID begins with `AC`.
</Expandable>

<Expandable title="Error 20429: Too Many Requests" default-open="false">
**Problem**

You receive HTTP 429 and the following response body:

```json
{
  "code": 20429,
  "message": "Too Many Requests",
  "more_info": "https://www.twilio.com/docs/errors/20429"
}
```

**Cause**

Your account has exceeded the per-second or per-minute request limit for the endpoint.

**Fix**

Implement exponential backoff in your client. Space requests at least 1 second apart for high-volume endpoints. Review your account's rate limits in the Twilio console under API keys.
</Expandable>

<Expandable title="Error 21606: Invalid 'From' Phone Number" default-open="false">
**Problem**

You receive HTTP 400 and the following response body:

```json
{
  "code": 21606,
  "message": "The 'From' phone number is not a valid phone number or short code.",
  "more_info": "https://www.twilio.com/docs/errors/21606"
}
```

**Cause**

The `From` parameter references a number that is not owned by your account or is not a valid Twilio number.

**Fix**

Use a phone number purchased through your Twilio account or a verified caller ID. Retrieve your numbers via the Incoming Phone Numbers resource before sending.
</Expandable>
