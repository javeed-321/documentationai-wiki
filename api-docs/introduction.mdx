## Welcome

Use the Vercel REST API to manage projects, deployments, and teams from code. You can automate delivery across the platform and keep operational changes consistent with your workflows.

This starter page gives you a fast map of the API surface, along with the versioning and rate limit rules you should account for before you integrate.
