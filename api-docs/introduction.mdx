## Welcome

Twilio gives you a Customer Engagement Platform for building direct, personalized communication across voice, SMS, WhatsApp, and email. You use web APIs to create customer journeys that connect sales, marketing, support, and service.

Twilio operates in 180 countries and supports the infrastructure you need to reach customers on their preferred channels. Start with the platform capabilities below, then explore the Voice and messaging documentation that fits your application.
