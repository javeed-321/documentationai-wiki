## Welcome

Stripe gives you a REST API for payments, billing, Connect, Radar, and financial reporting. You use it to create online, in-app, and in-person commerce flows across many currencies and payment methods.

This introduction covers the core API patterns you need to start safely: versioning, request format, webhooks, and idempotency. Use these concepts as the base for every integration you build.
