## Welcome

The PlanetScale API provides programmatic access to manage databases, branches, and deploy requests. Use standard REST methods to interact with resources through authenticated endpoints.

<Columns cols={2}>
  <Card title="REST basics" icon="code" href="#rest">
    Issue requests with GET, POST, PATCH, and DELETE against versioned endpoints.
  </Card>
  <Card title="Resource model" icon="database" href="#resources">
    Operate on databases, branches, deploy requests, and related objects.
  </Card>
  <Card title="Authentication" icon="lock" href="#auth">
    Supply an API token in the Authorization header for every request.
  </Card>
  <Card title="Rate limits" icon="bar-chart" href="#limits">
    Requests are limited to 100 per minute per token.
  </Card>
</Columns>
