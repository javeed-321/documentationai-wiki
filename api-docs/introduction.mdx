## Welcome

The Stripe API provides a REST interface for accepting payments, managing billing, and accessing financial services. You send HTTPS requests to endpoints that support JSON request and response bodies.

## Core capabilities

<Columns cols={2}>
  <Card title="REST API" icon="code" href="#">
    Standard HTTP methods and resource-oriented URLs handle all operations for payments, customers, and subscriptions.
  </Card>
  <Card title="Payment methods" icon="credit-card" href="#">
    Support for cards, bank transfers, wallets, and local payment options across more than 135 currencies.
  </Card>
  <Card title="Idempotency" icon="refresh-cw" href="#">
    Supply an Idempotency-Key header to safely retry requests without duplicating side effects.
  </Card>
  <Card title="Rate limits" icon="gauge" href="#">
    Default limits of 100 read and 100 write requests per second per account with clear retry guidance.
  </Card>
</Columns>
