## Welcome

The ShopifyMax API exposes endpoints for checkout operations under three seconds and catalog access for more than one hundred thousand products. It accepts `CART_TOKEN` and `PAYMENT_KEY` variables on every request.

  </Card>
  <Card title="Catalog Access" icon="database">
