## Welcome

Stripe gives you REST APIs for payments, billing, Connect, Radar, and reporting. You use webhooks to react to events, idempotency to safely retry requests, and pagination to move through large result sets.

Its platform supports online, in-app, and in-person transactions in more than 135 currencies. Build against stable versions, handle rate limits explicitly, and design for event-driven workflows from the start.
