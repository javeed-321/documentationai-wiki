## Welcome

ShopifyMax exposes client API endpoints for brand projects, asset delivery, and campaign tracking. You use it to create, update, and monitor work across travel, hospitality, luxury, and lifestyle programs.

The reference pages in this section show the core resource model and the request patterns you use in production. Start with project lifecycle operations, then move into asset distribution and tracking events.
