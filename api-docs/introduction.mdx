## Welcome

The Vercel REST API lets you manage projects, deployments, and domains directly from your applications. Use it to automate workflows and integrate Vercel into your existing tools.

<Columns cols={2}>
  <Card title="API Capabilities" icon="zap" href="#capabilities">
    Control projects, deployments, and domains through a unified set of endpoints.
  </Card>
  <Card title="Rate Limits" icon="shield" href="#limits">
    Requests are limited to 100 per minute per token to ensure stability.
  </Card>
  <Card title="Response Formats" icon="code" href="#formats">
    All responses return JSON with consistent error and success structures.
  </Card>
  <Card title="Versioning" icon="settings" href="#versioning">
    The current stable version is v2. Include the version in the request path.
  </Card>
</Columns>
