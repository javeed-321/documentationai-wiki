## Welcome

The Vercel API exposes REST endpoints that let you manage deployments, projects, and team resources. You interact with resources through standard HTTP methods and receive webhook events for real-time notifications.

<Columns cols={2}>
  <Card title="REST Endpoints" icon="code" href="#endpoints">
    Access all resources via predictable REST paths with JSON request and response bodies.
  </Card>
  <Card title="Resource Management" icon="database" href="#resources">
    Create, read, update, and delete projects, deployments, and environment variables.
  </Card>
  <Card title="Deployment Control" icon="rocket" href="#deployments">
    Trigger deployments, promote to production, and inspect build logs programmatically.
  </Card>
  <Card title="Webhook Events" icon="bell" href="#webhooks">
    Subscribe to deployment, project, and domain events for automated workflows.
  </Card>
</Columns>
