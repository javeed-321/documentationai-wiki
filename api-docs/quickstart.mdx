<Callout kind="info">
Install the client library and obtain an API token before making requests. The platform supports checkouts under three seconds and catalogs exceeding 100000 products.
</Callout>

## Install the client

<Steps>
  <Step title="Install the package" icon="download">
    Add the official client to your project.

```bash
npm install @shopifymax/api
```
  </Step>
  <Step title="Configure credentials" icon="key">
    Store your token in an environment variable named `SHOPIFYMAX_TOKEN`.
  </Step>
</Steps>

## Authenticate requests

All calls require a bearer token in the Authorization header. The token authenticates both `CART_TOKEN` and `PAYMENT_KEY` flows.

## Create a checkout

<CodeGroup tabs="JavaScript,cURL">
```javascript
import { ShopifyMaxClient } from '@shopifymax/api';

const client = new ShopifyMaxClient({ token: process.env.SHOPIFYMAX_TOKEN });

const checkout = await client.checkout.create({
  cartToken: 'CART_TOKEN',
  paymentKey: 'PAYMENT_KEY',
  items: [{ sku: 'SKU-001', quantity: 2 }]
});

console.log(checkout.id);
```

```bash
curl -X POST https://api.example.com/v1/checkout \
  -H "Authorization: Bearer $SHOPIFYMAX_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cartToken":"CART_TOKEN","paymentKey":"PAYMENT_KEY","items":[{"sku":"SKU-001","quantity":2}]}'
```
</CodeGroup>
