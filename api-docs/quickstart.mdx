## Prerequisites

<Callout kind="info">
Create a free Twilio account and verify your email address before proceeding. You also need at least one phone number purchased from the Twilio console.
</Callout>

## Account Setup and Phone Number Purchase

<Steps>
<Step title="Create credentials" icon="key">
Log in to the Twilio console and copy your Account SID and Auth Token from the dashboard. Store these values securely.
</Step>
<Step title="Buy a number" icon="phone">
Navigate to Phone Numbers in the console, search for an available number that supports SMS, and complete the purchase.
</Step>
</Steps>

## Send Your First SMS

Use the REST API to send an outbound message. The examples below use your Account SID, Auth Token, and purchased phone number.

<CodeGroup tabs="cURL,Python">
```bash
curl -X POST https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Messages.json \
  --data-urlencode "From=+15551234567" \
  --data-urlencode "To=+15559876543" \
  --data-urlencode "Body=Hello from Twilio" \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```
```python
from twilio.rest import Client

client = Client("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")
message = client.messages.create(
    from_="+15551234567",
    to="+15559876543",
    body="Hello from Twilio"
)
print(message.sid)
```
</CodeGroup>

## Handle Inbound Messages via Webhooks

Configure a webhook URL in the Twilio console under the phone number settings. Twilio posts form-encoded data to this endpoint when a message arrives.

<Steps>
<Step title="Set webhook URL" icon="link">
Enter your publicly accessible endpoint (for example `https://example.com/webhook`) in the Messaging webhook field.
</Step>
<Step title="Respond to the request" icon="code">
Return TwiML in your handler to reply automatically.
</Step>
</Steps>

```python
from flask import Flask, request
from twilio.twiml.messaging_response import MessagingResponse

app = Flask(__name__)

@app.route("/webhook", methods=["POST"])
def webhook():
    resp = MessagingResponse()
    resp.message("Thanks for your message!")
    return str(resp)

if __name__ == "__main__":
    app.run()
```
