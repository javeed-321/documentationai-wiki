## Prerequisites

<Callout kind="info">
You need a Twilio account and a phone number before making API calls. Sign up at `https://www.twilio.com` if you do not have an account.
</Callout>

## Obtain a Twilio phone number

<Steps>
  <Step title="Sign in to the Console" icon="log-in">
    Log in to the Twilio Console and navigate to the Phone Numbers section.
  </Step>
  <Step title="Search and buy a number" icon="search">
    Search for a number that supports SMS and Voice capabilities. Purchase the number.
  </Step>
  <Step title="Note the number and credentials" icon="key">
    Record the purchased phone number, Account SID, and Auth Token from the Console dashboard.
  </Step>
</Steps>

## Make your first API call

Use the following code to place an outbound voice call. Replace the placeholder values with your Account SID, Auth Token, and phone numbers.

<CodeGroup tabs="Node.js,Python">
```javascript
const twilio = require("twilio");

const accountSid = "YOUR_ACCOUNT_SID";
const authToken = "YOUR_AUTH_TOKEN";
const client = twilio(accountSid, authToken);

client.calls
  .create({
    to: "+15551234567",
    from: "+15559876543",
    url: "https://example.com/voice.xml",
  })
  .then((call) => console.log(call.sid));
```

```python
from twilio.rest import Client

account_sid = "YOUR_ACCOUNT_SID"
auth_token = "YOUR_AUTH_TOKEN"
client = Client(account_sid, auth_token)

call = client.calls.create(
    to="+15551234567",
    from_="+15559876543",
    url="https://example.com/voice.xml"
)

print(call.sid)
```
</CodeGroup>
