## Prerequisites

<Callout kind="info">
  You need a Twilio account and an API key. Sign up at https://www.twilio.com if you do not already have one.
</Callout>

## Account Setup

<Steps>
  <Step title="Create a Twilio account">
    Visit the Twilio website and complete the sign-up process. Verify your email address to activate the account.
  </Step>
  <Step title="Obtain credentials">
    Log in to the Twilio Console. Copy your Account SID and Auth Token from the dashboard.
  </Step>
  <Step title="Purchase a phone number">
    From the Console, buy a phone number that supports SMS, voice, or WhatsApp as needed for your use case.
  </Step>
</Steps>

## Send an SMS

Use the REST API to send a text message.

<CodeGroup tabs="cURL,Node.js,Python">
```bash
curl -X POST https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Messages.json \
  --data-urlencode "From=+15005550006" \
  --data-urlencode "Body=Hello from Twilio" \
  --data-urlencode "To=+15005550006" \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```

```js
const accountSid = "YOUR_ACCOUNT_SID";
const authToken = "YOUR_AUTH_TOKEN";
const client = require("twilio")(accountSid, authToken);

client.messages
  .create({
    body: "Hello from Twilio",
    from: "+15005550006",
    to: "+15005550006",
  })
  .then((message) => console.log(message.sid));
```

```python
from twilio.rest import Client

account_sid = "YOUR_ACCOUNT_SID"
auth_token = "YOUR_AUTH_TOKEN"
client = Client(account_sid, auth_token)

message = client.messages.create(
    body="Hello from Twilio",
    from_="+15005550006",
    to="+15005550006",
)
print(message.sid)
```
</CodeGroup>

## Initiate a Voice Call

Place an outbound voice call using TwiML.

<CodeGroup tabs="cURL,Node.js,Python">
```bash
curl -X POST https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Calls.json \
  --data-urlencode "From=+15005550006" \
  --data-urlencode "To=+15005550006" \
  --data-urlencode "Url=https://example.com/voice.xml" \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```

```js
client.calls
  .create({
    url: "https://example.com/voice.xml",
    from: "+15005550006",
    to: "+15005550006",
  })
  .then((call) => console.log(call.sid));
```

```python
call = client.calls.create(
    url="https://example.com/voice.xml",
    from_="+15005550006",
    to="+15005550006",
)
print(call.sid)
```
</CodeGroup>

## Send a WhatsApp Message

Send messages over WhatsApp using the same Messages resource.

<CodeGroup tabs="cURL,Node.js,Python">
```bash
curl -X POST https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Messages.json \
  --data-urlencode "From=whatsapp:+14155238886" \
  --data-urlencode "Body=Hello from Twilio WhatsApp" \
  --data-urlencode "To=whatsapp:+15005550006" \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```

```js
client.messages

    body: "Hello from Twilio WhatsApp",
    from: "whatsapp:+14155238886",
    to: "whatsapp:+15005550006",
  })
  .then((message) => console.log(message.sid));
```

```python
message = client.messages.create(
    body="Hello from Twilio WhatsApp",
    from_="whatsapp:+14155238886",

```
</CodeGroup>
