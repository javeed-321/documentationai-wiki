## Prerequisites

<Callout kind="info">
Obtain an API token from your account settings before making any requests. All calls require the `Authorization: Bearer YOUR_API_TOKEN` header.
</Callout>

## Generate an API token

<Steps>
<Step title="Create token" icon="key">
Open the dashboard at `https://dashboard.example.com/settings/tokens` and generate a new token with project read and deployment write scopes.
</Step>
<Step title="Store token" icon="lock">
Save the token as an environment variable named `VERCEL_TOKEN`. Never commit it to source control.
</Step>
</Steps>

## List projects

<CodeGroup tabs="cURL,JavaScript,Python">
```bash
curl -H "Authorization: Bearer $VERCEL_TOKEN" \
  https://api.example.com/v2/projects
```
```javascript
const res = await fetch("https://api.example.com/v2/projects", {
  headers: { Authorization: `Bearer ${process.env.VERCEL_TOKEN}` },
});
const projects = await res.json();
console.log(projects);
```
```python
import requests
import os

headers = {"Authorization": f"Bearer {os.environ['VERCEL_TOKEN']}"}
response = requests.get("https://api.example.com/v2/projects", headers=headers)
print(response.json())
```
</CodeGroup>

## Trigger a deployment

<CodeGroup tabs="cURL,JavaScript,Python">
```bash
curl -X POST \
  -H "Authorization: Bearer $VERCEL_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"my-app","gitRepository":{"url":"https://github.com/example/repo"}}' \
  https://api.example.com/v13/deployments
```
```javascript
const res = await fetch("https://api.example.com/v13/deployments", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VERCEL_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "my-app",
    gitRepository: { url: "https://github.com/example/repo" },
  }),
});
const deployment = await res.json();
```
```python
import requests
import os

headers = {
    "Authorization": f"Bearer {os.environ['VERCEL_TOKEN']}",
    "Content-Type": "application/json",
}
data = {
    "name": "my-app",
    "gitRepository": {"url": "https://github.com/example/repo"},
}
response = requests.post(
    "https://api.example.com/v13/deployments", headers=headers, json=data
)
print(response.json())
```
</CodeGroup>
