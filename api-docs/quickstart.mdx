## Prerequisites

<Callout kind="info">
Obtain an API key from your Trigger.dev dashboard before making requests.
</Callout>

## Authenticate requests

Include the API key in the Authorization header for every call.

## List projects and trigger a run

<Steps>
<Step title="List projects">
Send a GET request to retrieve your projects.

````bash
curl -X GET https://api.example.com/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
````

</Step>
<Step title="Trigger a run">
Send a POST request to start a task run.

````bash
curl -X POST https://api.example.com/v1/tasks/runs \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "task": "example-task",
    "payload": {}
  }'
````

</Step>
</Steps>
