## Prerequisites

<Callout kind="info">
You need a Vercel account. Generate a personal access token from your account settings before proceeding.
</Callout>

## Obtain an access token

Create a token with deployment scope. Store it securely and reference it as an environment variable.

```bash
export VERCEL_TOKEN=your_token_here
```

## Create a project and trigger a deployment

<Steps>
  <Step title="Create project" icon="folder-plus">
    Send a POST request to create a new project.

    ```bash
    curl -X POST https://api.example.com/v1/projects \
      -H "Authorization: Bearer $VERCEL_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{"name":"my-project"}'
    ```
  </Step>
  <Step title="Trigger deployment" icon="rocket">
    Deploy from a Git repository URL.

    ```bash
    curl -X POST https://api.example.com/v1/deployments \
      -H "Authorization: Bearer $VERCEL_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{"projectId":"prj_xxx","gitSource":{"type":"github","repo":"owner/repo"}}'
    ```
  </Step>
</Steps>

## Poll deployment status

<CodeGroup tabs="cURL,Node.js">
```bash
curl https://api.example.com/v1/deployments/dpl_xxx \
  -H "Authorization: Bearer $VERCEL_TOKEN"
```

```js
const res = await fetch('https://api.example.com/v1/deployments/dpl_xxx', {
  headers: { Authorization: `Bearer ${process.env.VERCEL_TOKEN}` }
});
const data = await res.json();
console.log(data.status);
```
</CodeGroup>
