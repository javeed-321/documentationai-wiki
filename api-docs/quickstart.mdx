## Prerequisites

<Callout kind="info">
Create a Stripe account and obtain your secret and publishable API keys from the dashboard before you begin.
</Callout>

## Create your first charge

Use your secret key to create a charge in test mode.

<CodeGroup tabs="Node.js,Python,Ruby">
```javascript
const stripe = require("stripe")("sk_test_your_key_here");

const charge = await stripe.charges.create({
  amount: 2000,
  currency: "usd",
  source: "tok_visa",
  description: "Test charge",
});
```
```python
import stripe
stripe.api_key = "sk_test_your_key_here"

charge = stripe.Charge.create(
    amount=2000,
    currency="usd",
    source="tok_visa",
    description="Test charge",
)
```
```ruby
require "stripe"
Stripe.api_key = "sk_test_your_key_here"

charge = Stripe::Charge.create({
  amount: 2000,
  currency: "usd",
  source: "tok_visa",
  description: "Test charge",
})
```
</CodeGroup>

## Handle webhooks

Register an endpoint that receives event notifications such as `charge.succeeded`.

```bash
curl -X POST https://api.example.com/webhook \
  -H "Stripe-Signature: t=123456,v1=abc123" \
  -d '{"type":"charge.succeeded"}'
```
