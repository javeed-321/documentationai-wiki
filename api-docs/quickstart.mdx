## Prerequisites

<Callout kind="info">
Create a Twilio account and retrieve your Account SID and Auth Token from the console. You also need a phone number capable of sending SMS or making voice calls.
</Callout>

## Obtain a Twilio phone number

Log in to the console and navigate to the phone numbers section. Search for and purchase a number that supports the required capabilities.

## Send an SMS via REST API

<Steps>
  <Step title="Set credentials">
    Export your Account SID and Auth Token as environment variables.
  </Step>
  <Step title="Execute the request">
    Issue a POST request to the Messages resource.
  </Step>
</Steps>

<CodeGroup tabs="cURL,Python">
```bash
curl -X POST https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Messages.json \
  --data-urlencode "From=+15005550006" \
  --data-urlencode "To=+15005550006" \
  --data-urlencode "Body=Hello from Twilio" \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```
```python
import requests
response = requests.post(
    "https://api.twilio.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID/Messages.json",
    auth=("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN"),
    data={"From": "+15005550006", "To": "+15005550006", "Body": "Hello from Twilio"}
)
print(response.json())
```
</CodeGroup>

## Handle incoming webhooks

Configure your webhook URL in the phone number settings. Your server must respond with valid TwiML.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Message>Thanks for contacting us.</Message>
</Response>
```
