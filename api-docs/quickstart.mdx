## Quickstart

Use this quickstart to make your first API call with Stripe. You will set up an API key, send a test request, and verify the response in a few minutes.

<Callout kind="info">

This page uses test mode only. Replace `YOUR_API_KEY` with a test secret key before you send requests.

</Callout>

## What you need

Before you start, make sure you have the following:

- A Stripe account with access to the dashboard
- A test secret key
- `curl`, or a supported client library
- A terminal that can reach `https://api.example.com`

## Set up your environment

Follow these steps to prepare your first request.

<Steps>
  <Step title="Create a test key" icon="key">

  In the Stripe dashboard, create or copy a test secret key. Store it as an environment variable so you do not hardcode it in requests.

  </Step>
  <Step title="Choose a request type" icon="settings">

  Start with either a customer create request or a payment request. This page shows a customer example first, because it is the smallest working call.

  </Step>
  <Step title="Send a test request" icon="terminal">

  Run the sample request from your terminal and confirm you receive a `200`-level response.

  </Step>
</Steps>

## Make your first request

Use the `customers` endpoint to create a test customer. This is a minimal request that confirms authentication, network access, and request formatting.

<CodeGroup tabs="cURL,JavaScript,Python">
  ```bash
curl https://api.example.com/v1/customers \
  -u YOUR_API_KEY: \
  -d email="jane.doe@example.com" \
  -d name="Jane Doe"
  ```

  ```javascript
const response = await fetch("https://api.example.com/v1/customers", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/x-www-form-urlencoded",
  },
  body: new URLSearchParams({
    email: "jane.doe@example.com",
    name: "Jane Doe",
  }),
});

const customer = await response.json();
console.log(customer);
  ```

  ```python
import requests

response = requests.post(
    "https://api.example.com/v1/customers",
    auth=("YOUR_API_KEY", ""),
    data={
        "email": "jane.doe@example.com",
        "name": "Jane Doe",
    },
)

customer = response.json()
print(customer)
  ```
</CodeGroup>

## Use test data

Stripe provides test values so you can validate your integration without moving money. Use them to simulate success and error cases while you build.

<Tabs>
  <Tab title="Cards" icon="credit-card">

  Use a test card number to simulate a successful payment. Keep all other values realistic, such as an email address and billing name.

  </Tab>
  <Tab title="Customers" icon="users">

  Create customers with test email addresses so you can attach them to future requests for subscriptions, invoices, or saved payment methods.

  </Tab>
  <Tab title="Errors" icon="alert-triangle">

  Use invalid or incomplete input to confirm your error handling returns a useful message to the caller.

  </Tab>
</Tabs>

## Common checks

Before you ship, verify the basics in test mode.

<Expandable title="Troubleshooting checklist" default-open="false">

- Confirm that `YOUR_API_KEY` is a test key.
- Make sure the request uses the correct endpoint path.
- Check that the request body is form encoded when the API expects it.
- Inspect the response body for validation errors.
- Retry with test data before you use live mode.

</Expandable>
