## Prerequisites

<Callout kind="info">
Obtain an API token from the dashboard before making requests. All requests require the Authorization header with a Bearer token.
</Callout>

## Make your first request

Follow these steps to list databases and create a branch.

<Steps>
  <Step title="Prepare credentials" icon="key">
    Store your token in an environment variable:

    ```bash
    export PLANETSCALE_TOKEN="YOUR_API_KEY"
    ```
  </Step>
  <Step title="List databases" icon="database">
    Send a GET request to retrieve available databases.

    <CodeGroup tabs="cURL,JavaScript,Python">
      ```bash
      curl -H "Authorization: Bearer $PLANETSCALE_TOKEN" \
        https://api.example.com/v1/databases
      ```

      ```javascript
      const res = await fetch("https://api.example.com/v1/databases", {
        headers: { Authorization: `Bearer ${process.env.PLANETSCALE_TOKEN}` },
      });
      const data = await res.json();
      console.log(data);
      ```

      ```python
      import requests
      import os

      headers = {"Authorization": f"Bearer {os.environ['PLANETSCALE_TOKEN']}"}
      response = requests.get("https://api.example.com/v1/databases", headers=headers)
      print(response.json())
      ```
    </CodeGroup>
  </Step>
  <Step title="Create a branch" icon="git-branch">
    Create a new branch from the main branch of a database.

    <CodeGroup tabs="cURL,JavaScript,Python">
      ```bash
      curl -X POST \
        -H "Authorization: Bearer $PLANETSCALE_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"name":"feature-x","parent":"main"}' \
        https://api.example.com/v1/databases/mydb/branches
      ```

      ```javascript
      const res = await fetch(
        "https://api.example.com/v1/databases/mydb/branches",
        {
          method: "POST",
          headers: {
            Authorization: `Bearer ${process.env.PLANETSCALE_TOKEN}`,
            "Content-Type": "application/json",
          },
          body: JSON.stringify({ name: "feature-x", parent: "main" }),
        }
      );
      const data = await res.json();
      console.log(data);
      ```

      ```python
      import requests
      import os

      headers = {
          "Authorization": f"Bearer {os.environ['PLANETSCALE_TOKEN']}",
          "Content-Type": "application/json",
      }
      payload = {"name": "feature-x", "parent": "main"}
      response = requests.post(
          "https://api.example.com/v1/databases/mydb/branches",
          headers=headers,
          json=payload,
      )
      print(response.json())
      ```
    </CodeGroup>
  </Step>
</Steps>

## Handling responses

Successful responses return JSON with a `data` array or object. Errors include an `error` field and appropriate HTTP status codes.

Check the response status before processing:

```javascript
if (!res.ok) {
  const err = await res.json();
  throw new Error(err.error);
}
```
