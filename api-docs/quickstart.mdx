## Prerequisites

<Callout kind="info">
  You need a ShopifyMax store and an Admin API access token with read permissions for products and orders.
</Callout>

## Set up the API client

<Steps>
  <Step title="Install the client library">
    Choose your language and install the official library.

  </Step>
  <Step title="Configure credentials">
    Store your access token in an environment variable named `SHOPIFY_ACCESS_TOKEN`.

  </Step>
</Steps>

## Make your first request

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const response = await fetch(
  "https://api.example.com/admin/api/2024-01/graphql.json",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Shopify-Access-Token": process.env.SHOPIFY_ACCESS_TOKEN,
    },
    body: JSON.stringify({
      query: "{ products(first: 5) { edges { node { id title } } } }",
    }),
  }
);
const data = await response.json();
console.log(data);
```

```python
import requests
import os

query = "{ products(first: 5) { edges { node { id title } } } }"
headers = {"X-Shopify-Access-Token": os.environ["SHOPIFY_ACCESS_TOKEN"]}
response = requests.post(
    "https://api.example.com/admin/api/2024-01/graphql.json",
    json={"query": query},
    headers=headers,
)
print(response.json())
```

```bash
curl -X POST \
  https://api.example.com/admin/api/2024-01/graphql.json \
  -H "Content-Type: application/json" \
  -H "X-Shopify-Access-Token: $SHOPIFY_ACCESS_TOKEN" \
  -d '{"query":"{ products(first: 5) { edges { node { id title } } } }"}'
```
</CodeGroup>

## Register a webhook

```bash
curl -X POST \
  https://api.example.com/admin/api/2024-01/webhooks.json \
  -H "Content-Type: application/json" \
  -H "X-Shopify-Access-Token: $SHOPIFY_ACCESS_TOKEN" \
  -d '{"webhook":{"topic":"orders/create","address":"https://example.com/webhooks/orders"}}'
```
