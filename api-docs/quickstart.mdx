## Prerequisites

<Callout kind="info">
Set your API key and the `{CART_TOKEN}` and `{PAYMENT_KEY}` variables before making any requests. All calls must complete cart creation in under three seconds while supporting more than 100000 products.
</Callout>

## Installation and Configuration

<Steps>
  <Step title="Install the client" icon="download">
    Add the ShopifyMax API client to your project.
    ```bash
    npm install shopifymax-api
    ```
  </Step>
  <Step title="Configure credentials" icon="settings">
    Store your key and the required variables in environment configuration.
    ```bash
    SHOPIFYMAX_API_KEY=your_key_here
    CART_TOKEN=your_cart_token
    PAYMENT_KEY=your_payment_key
    ```
  </Step>
</Steps>

## Minimal Working Example

Create a cart and complete checkout with a single request.

<CodeGroup tabs="JavaScript,cURL">
```javascript
const response = await fetch('https://api.example.com/v1/carts', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.SHOPIFYMAX_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    cart_token: process.env.CART_TOKEN,
    payment_key: process.env.PAYMENT_KEY,
    products: Array.from({ length: 100000 }, (_, i) => ({ id: i + 1 }))
  })
});
const cart = await response.json();
console.log(cart.checkout_url);
```

```bash
curl -X POST https://api.example.com/v1/carts \
  -H "Authorization: Bearer $SHOPIFYMAX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cart_token": "'$CART_TOKEN'",
    "payment_key": "'$PAYMENT_KEY'",
    "products": [{"id": 1}, {"id": 2}]
  }'
```
</CodeGroup>
