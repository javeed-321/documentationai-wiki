## Overview

All requests to the ShopifyMax API require authentication. You send credentials with every request so the platform can verify your identity and enforce the correct access scopes.

ShopifyMax supports two primary authentication methods: OAuth for public apps and API keys for private apps. Both return an access token that you include in subsequent calls.

## Authentication methods

<Tabs>
  <Tab title="OAuth" icon="key">

  OAuth is the recommended flow for public apps that merchants install from the ShopifyMax App Store.

  </Tab>
  <Tab title="Private apps" icon="lock">

  Private apps use a static API key and secret generated inside a single store.

  </Tab>
</Tabs>

## OAuth flow

1. Redirect the merchant to the ShopifyMax authorization URL.
2. The merchant grants the requested scopes.
3. ShopifyMax redirects back with a temporary code.
4. Exchange the code for a permanent access token.

<ParamField query="client_id" param-type="string" required="true">
  Your app's client identifier.
</ParamField>

<ParamField query="scope" param-type="string" required="true">
  Space-separated list of requested access scopes.
</ParamField>

<ParamField query="redirect_uri" param-type="string" required="true">
  URL that receives the authorization code.
</ParamField>

## Implementation

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const token = await exchangeCodeForToken({
  clientId: "YOUR_CLIENT_ID",
  clientSecret: "YOUR_CLIENT_SECRET",
  code: req.query.code,
});
```
```python
token = exchange_code_for_token(
    client_id="YOUR_CLIENT_ID",
    client_secret="YOUR_CLIENT_SECRET",
    code=request.args.get("code"),
)
```
```bash
curl -X POST https://api.example.com/oauth/token \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET \
  -d code=AUTH_CODE
```
</CodeGroup>

Include the resulting access token in the Authorization header of every API call.

## Security recommendations

<Callout kind="alert">
Store access tokens securely. Never expose them in client-side code or commit them to version control. Rotate tokens when a merchant uninstalls your app.
</Callout>
