## Overview

Vercel API requests require authentication via access tokens. You send the token in the Authorization header for every request. Two primary methods exist: personal access tokens for individual use and OAuth2 for applications.

## Authentication Methods

<Tabs>
  <Tab title="Personal Access Tokens" icon="key">
    Generate a personal access token from your account settings. This token grants access scoped to your permissions.

    <ParamField header="Authorization" param-type="string" required="true">
      Use the format `Bearer YOUR_TOKEN` where YOUR_TOKEN is the personal access token value.
    </ParamField>
  </Tab>
  <Tab title="OAuth2" icon="lock">
    Register an OAuth application to obtain client credentials. Users authorize your app to receive scoped tokens.

    <ParamField header="Authorization" param-type="string" required="true">
      Use the format `Bearer OAUTH_ACCESS_TOKEN` after completing the OAuth2 flow.
    </ParamField>
  </Tab>
</Tabs>

## Implementation

Send authenticated requests using the token in the header. The examples below demonstrate usage across languages.

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const response = await fetch('https://api.example.com/v1/deployments', {
  headers: {
    Authorization: 'Bearer YOUR_TOKEN',
  },
});
```
```python
import requests

response = requests.get(
    'https://api.example.com/v1/deployments',
    headers={'Authorization': 'Bearer YOUR_TOKEN'}
)
```
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://api.example.com/v1/deployments
```
</CodeGroup>

## Security Considerations

<Callout kind="alert">
Rotate tokens regularly and revoke unused ones immediately. Store tokens only in secure environments and never commit them to source control. Limit scopes to the minimum permissions required for each token.
</Callout>
