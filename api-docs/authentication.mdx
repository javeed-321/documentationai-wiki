## Overview

Trigger.dev API requests require authentication using either a personal access token or a project API key. Include the credential in the Authorization header of every request. Unauthenticated requests return a 401 status.

## Authentication methods

<Tabs>
  <Tab title="Personal access tokens" icon="key">

    Personal access tokens authenticate requests on behalf of a user account. Generate tokens in the dashboard under Account settings. Tokens support scopes that limit access to specific resources.

    <ParamField header="Authorization" param-type="string" required="true">
      Use the format `Bearer YOUR_PERSONAL_ACCESS_TOKEN`.
    </ParamField>

  </Tab>
  <Tab title="Project API keys" icon="lock">

    Project API keys authenticate requests scoped to a single project. Create keys in the project settings. Keys inherit the permissions of the project owner.

    <ParamField header="Authorization" param-type="string" required="true">
      Use the format `Bearer YOUR_PROJECT_API_KEY`.
    </ParamField>

  </Tab>
</Tabs>

## Sending authenticated requests

Use the Authorization header with every request. The examples below show the header in three languages.

<CodeGroup tabs="JavaScript,Python,cURL">
````javascript
const response = await fetch("https://api.example.com/v1/tasks", {
  method: "GET",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
});
````
````python
import requests

response = requests.get(
    "https://api.example.com/v1/tasks",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
    },
)
````
````bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     https://api.example.com/v1/tasks
````
</CodeGroup>

## Security best practices

<Callout kind="alert">

Store tokens and keys in environment variables. Never commit credentials to source control. Rotate keys regularly and revoke tokens immediately after suspected compromise. Limit token scopes to the minimum required permissions.

</Callout>
