## Overview

Every request to the Twilio REST API must include valid credentials. You authenticate using your Account SID paired with either an Auth Token or an API key. Twilio supports HTTP Basic Auth for direct requests and built-in credential handling inside the official helper libraries.

## Authentication methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">
    Your Account SID and Auth Token are created automatically when you sign up. Use them for all API calls until you generate API keys.

    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `Basic {base64(AccountSID:AuthToken)}`.
    </ParamField>
  </Tab>
  <Tab title="API Keys" icon="key">
    API keys provide scoped access and can be rotated independently of your primary account credentials. Create them in the Twilio Console under API keys.

    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `Basic {base64(APIKeySID:APIKeySecret)}`.
    </ParamField>
  </Tab>
</Tabs>

## Implementation examples

Use the following patterns to authenticate requests. Replace the placeholder values with your own credentials.

<CodeGroup tabs="cURL,Python,Node.js">
```bash
curl -X GET 'https://api.example.com/2010-04-01/Accounts/ACxxxxxxxx.json' \
  -u 'ACxxxxxxxx:your_auth_token'
```

```python
from twilio.rest import Client

client = Client('ACxxxxxxxx', 'your_auth_token')
account = client.api.accounts('ACxxxxxxxx').fetch()
print(account.friendly_name)
```

```javascript
const twilio = require('twilio');

const client = twilio('ACxxxxxxxx', 'your_auth_token');
client.api.accounts('ACxxxxxxxx')
  .fetch()
  .then(account => console.log(account.friendly_name));
```
</CodeGroup>

## Security recommendations

<Callout kind="alert">
Never commit Account SIDs, Auth Tokens, or API key secrets to source control. Store credentials in environment variables and rotate API keys on a regular schedule. Use API keys with the minimum required permissions for each application.
</Callout>
