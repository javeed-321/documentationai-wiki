## Overview

Every request to the Twilio REST API requires authentication. You supply either your Account SID paired with an Auth Token or an API key pair. Twilio validates credentials on each call and returns HTTP 401 for invalid or missing values.

## Authentication Methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">
    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `AccountSID:AuthToken`.
    </ParamField>

    Your Account SID begins with `AC` and your Auth Token is a 32-character secret. Both appear in the Twilio Console under Account Info.
  </Tab>
  <Tab title="API Keys" icon="key-round">
    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `APIKeySID:APIKeySecret`.
    </ParamField>

    API keys provide scoped access and support rotation without changing your main account credentials.
  </Tab>
</Tabs>

## Implementation

Use the following examples to authenticate requests. Replace placeholders with your own values.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/2010-04-01/Accounts \
  -u "ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx:your_auth_token"
```
```python
import requests

response = requests.get(
    "https://api.example.com/2010-04-01/Accounts",
    auth=("ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", "your_auth_token")
)
print(response.json())
```
```javascript
const response = await fetch("https://api.example.com/2010-04-01/Accounts", {
  headers: {
    Authorization: "Basic " + btoa("ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx:your_auth_token"),
  },
});
const data = await response.json();
console.log(data);
```
</CodeGroup>

## Security Best Practices

<Callout kind="alert">
Store credentials outside source code. Use environment variables or a secrets manager. Rotate API keys every 90 days and immediately revoke any key that may have been exposed. Never commit tokens to version control or share them in logs.
</Callout>

Create new keys from the Twilio Console under API Keys & Tokens. Delete old keys only after confirming all services have migrated to the new pair.
