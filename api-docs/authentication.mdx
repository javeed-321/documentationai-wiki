## Overview

Stripe authenticates every API request using API keys. Include the appropriate key in the Authorization header of each request. Keep secret keys confidential and never expose them in client-side code.

## API key types

<Tabs>
  <Tab title="Secret keys" icon="key">
    Use secret keys for server-side requests. They grant full access to your Stripe account.

    <ParamField header="Authorization" param-type="string" required="true">
      Bearer token using your secret key in the format `Bearer sk_live_...`.
    </ParamField>
  </Tab>
  <Tab title="Publishable keys" icon="key">
    Use publishable keys in client-side code. They are safe to expose publicly and identify your account.

    <ParamField header="Authorization" param-type="string" required="true">
      Bearer token using your publishable key in the format `Bearer pk_live_...`.
    </ParamField>
  </Tab>
  <Tab title="Restricted keys" icon="lock">
    Restricted keys limit access to specific permissions. Generate them in the Dashboard for least-privilege access.

    <ParamField header="Authorization" param-type="string" required="true">
      Bearer token using your restricted key in the format `Bearer rk_live_...`.
    </ParamField>
  </Tab>
</Tabs>

## Authenticated requests

Include the key in every request. The examples below demonstrate usage across languages.

<CodeGroup tabs="cURL,Python,Node.js">
```bash
curl https://api.stripe.com/v1/charges \
  -u sk_test_your_key_here: \
  -d amount=2000 \
  -d currency=usd \
  -d source=tok_visa
```

```python
import stripe
stripe.api_key = "sk_test_your_key_here"

charge = stripe.Charge.create(
  amount=2000,
  currency="usd",
  source="tok_visa",
)
```

```javascript
const stripe = require("stripe")("sk_test_your_key_here");

const charge = await stripe.charges.create({
  amount: 2000,
  currency: "usd",
  source: "tok_visa",
});
```
</CodeGroup>

## Webhook signatures

Verify webhook signatures to confirm events originate from Stripe.

<ParamField header="Stripe-Signature" param-type="string" required="true">
  Signature header containing timestamp and HMAC signature.
</ParamField>

Use your webhook endpoint secret to validate the payload before processing.

## Security practices

<Callout kind="alert">
  Never commit secret keys to source control. Rotate keys regularly and restrict permissions with limited keys when possible. Ensure all card data handling meets PCI compliance requirements.
</Callout>
