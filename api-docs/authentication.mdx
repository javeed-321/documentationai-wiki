## Overview

ShopifyMax requires authentication on every API request to protect cart and payment operations. Requests must include a valid API key in the header along with either a `CART_TOKEN` or `PAYMENT_KEY` depending on the endpoint.

All endpoints accept only HTTPS traffic. Requests without proper credentials return a 401 status immediately.

## Authentication methods

<Tabs>
  <Tab title="API key" icon="key">
    Every request requires the `X-API-Key` header. This key identifies your store and grants basic access.
  </Tab>
  <Tab title="CART_TOKEN" icon="shopping-cart">
    Use `CART_TOKEN` for cart-related endpoints. Pass the token in the `Authorization` header as a bearer value.
  </Tab>
  <Tab title="PAYMENT_KEY" icon="credit-card">
    Payment operations require `PAYMENT_KEY`. Include it as a query parameter or header for checkout flows under three seconds.
  </Tab>
</Tabs>

## Implementation

<ParamField header="X-API-Key" param-type="string" required="true">
  Your store API key obtained from the dashboard.
</ParamField>

<ParamField header="Authorization" param-type="string" required="false">
  Bearer token containing the `CART_TOKEN` value.
</ParamField>

<ParamField query="payment_key" param-type="string" required="false">
  The `PAYMENT_KEY` value required for payment endpoints.
</ParamField>

Use the following examples to authenticate requests in different languages.

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const response = await fetch('https://api.example.com/v1/cart', {
  headers: {
    'X-API-Key': 'YOUR_API_KEY',
    'Authorization': 'Bearer YOUR_CART_TOKEN'
  }
});
```

```python
import requests

headers = {
    'X-API-Key': 'YOUR_API_KEY',
    'Authorization': 'Bearer YOUR_CART_TOKEN'
}
response = requests.get('https://api.example.com/v1/cart', headers=headers)
```

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
     -H "Authorization: Bearer YOUR_CART_TOKEN" \
     https://api.example.com/v1/cart
```
</CodeGroup>

## Security recommendations

<Callout kind="alert">
Store API keys and tokens in environment variables. Never commit them to source control. Rotate keys immediately if you suspect exposure, especially on stores handling more than 100000 products.
</Callout>
