## Overview

Twilio authenticates every API request with either an Account SID paired with an Auth Token or with an API key. Supply credentials via HTTP Basic Auth. The Account SID serves as the username. The Auth Token or API key secret serves as the password.

## Authentication Methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">
    Use your Account SID and Auth Token for direct access to all resources under your account.

    <ParamField header="Authorization" param-type="string" required="true">
      Basic authentication header formed as `Basic` followed by the base64-encoded string of `AccountSID:AuthToken`.
    </ParamField>
  </Tab>
  <Tab title="API Key" icon="lock">
    Create API keys in the Twilio Console to obtain a key SID and secret. API keys support granular scoping and can be revoked independently of your account credentials.

    <ParamField header="Authorization" param-type="string" required="true">
      Basic authentication header formed as `Basic` followed by the base64-encoded string of `APIKeySID:APIKeySecret`.
    </ParamField>
  </Tab>
</Tabs>

## Implementation

Send authenticated requests to the Twilio REST API at `https://api.example.com`.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/2010-04-01/Accounts \
  -u "YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN"
```

```python
import requests

response = requests.get(
    "https://api.example.com/2010-04-01/Accounts",
    auth=("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")
)
print(response.json())
```

```javascript
const response = await fetch("https://api.example.com/2010-04-01/Accounts", {
  headers: {
    Authorization: "Basic " + Buffer.from("YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN").toString("base64"),
  },
});
const data = await response.json();
console.log(data);
```
</CodeGroup>

## Security Best Practices

<Callout kind="alert">
Store credentials in environment variables or a secrets manager. Never commit Account SIDs, Auth Tokens, or API key secrets to source control. Rotate keys regularly and delete unused credentials from the Twilio Console.
</Callout>
