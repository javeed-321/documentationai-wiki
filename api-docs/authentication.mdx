## Overview

ShopifyMax uses token-based authentication for all API requests. Every call must include a valid `CART_TOKEN` or `PAYMENT_KEY` header. Requests without valid credentials return a 401 status.

## Authentication Methods

<Tabs>
  <Tab title="Cart Token" icon="key">
    Use `CART_TOKEN` for cart operations and session management.

    <ParamField header="X-Cart-Token" param-type="string" required="true">
      Unique cart identifier issued on session creation.
    </ParamField>
  </Tab>
  <Tab title="Payment Key" icon="lock">
    Use `PAYMENT_KEY` for payment and checkout flows.

    <ParamField header="X-Payment-Key" param-type="string" required="true">
      Secret key tied to the merchant account.
    </ParamField>
  </Tab>
</Tabs>

## Implementation

Send credentials in request headers. The examples below show the required format.

<CodeGroup tabs="JavaScript,Python,cURL">
```javascript
const res = await fetch('https://api.example.com/v1/cart', {
  headers: {
    'X-Cart-Token': 'ct_abc123',
    'Content-Type': 'application/json'
  }
});
```

```python
import requests

headers = {
    'X-Payment-Key': 'pk_live_xyz789',
    'Content-Type': 'application/json'
}
response = requests.get('https://api.example.com/v1/orders', headers=headers)
```

```bash
curl https://api.example.com/v1/products \
  -H "X-Cart-Token: ct_abc123" \
  -H "Content-Type: application/json"
```
</CodeGroup>

## Security Recommendations

<Callout kind="alert">
Store `PAYMENT_KEY` values only in secure server environments. Never expose them in client-side code or logs. Rotate keys immediately if a leak is suspected.
</Callout>
