## Overview

All requests to the PlanetScale API require authentication. You can authenticate using service tokens or OAuth 2.0. Service tokens are recommended for server-to-server integrations. OAuth is suited for applications that act on behalf of users or organizations.

## Authentication methods

<Tabs>
  <Tab title="Service tokens" icon="key">
    Create a service token in the dashboard under Organization settings. Assign scopes that limit the token to specific actions such as read-only access or schema changes.

    <ParamField body="token" param-type="string" required="true">
      The service token identifier.
    </ParamField>

    <ParamField body="token_secret" param-type="string" required="true">
      The secret associated with the token. Store this value securely.
    </ParamField>
  </Tab>
  <Tab title="OAuth" icon="shield">
    OAuth flows are initiated per organization. Register your application to obtain a client ID and secret, then exchange an authorization code for an access token.
  </Tab>
</Tabs>

## Implementation

Use the examples below to send authenticated requests.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -H "Authorization: Bearer TOKEN_SECRET" \
  https://api.example.com/v1/organizations
```

```python
import requests

headers = {"Authorization": "Bearer TOKEN_SECRET"}
response = requests.get(
    "https://api.example.com/v1/organizations",
    headers=headers,
)
```

```javascript
const response = await fetch(
  "https://api.example.com/v1/organizations",
  {
    headers: {
      Authorization: "Bearer TOKEN_SECRET",
    },
  },
);
```
</CodeGroup>

## Rotating and revoking credentials

Rotate service token secrets regularly. Revoke a token immediately if it is compromised.

<Callout kind="alert">
  Never expose token secrets in client-side code or public repositories. Rotate credentials at least every 90 days.
</Callout>
