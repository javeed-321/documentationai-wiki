## Overview

Twilio authenticates every API request using HTTP Basic Auth. Supply either your Account SID paired with an Auth Token or an API Key SID paired with its Secret as the username and password. All requests must use HTTPS.

## Authentication Methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">
    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `AccountSID:AuthToken`.
    </ParamField>
    Use your primary Account SID and Auth Token for full account access.
  </Tab>
  <Tab title="API Key" icon="key">
    <ParamField header="Authorization" param-type="string" required="true">
      Base64-encoded string in the format `APIKeySID:APIKeySecret`.
    </ParamField>
    Create API Keys in the Twilio Console for scoped or revocable credentials.
  </Tab>
</Tabs>

## Implementation

Send requests to `https://api.example.com` with the Authorization header.

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID.json \
  -u YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN
```
```python
import requests
from requests.auth import HTTPBasicAuth

response = requests.get(
    "https://api.example.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID.json",
    auth=HTTPBasicAuth("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")
)
print(response.json())
```
```javascript
const response = await fetch(
  "https://api.example.com/2010-04-01/Accounts/YOUR_ACCOUNT_SID.json",
  {
    headers: {
      Authorization:
        "Basic " + Buffer.from("YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN").toString("base64"),
    },
  }
);
const data = await response.json();
console.log(data);
```
</CodeGroup>

## Security Best Practices

<Callout kind="alert">
Store credentials in environment variables. Rotate Auth Tokens or API Key Secrets regularly. Never embed secrets in client-side code. Use API Keys with limited permissions when possible.
</Callout>
