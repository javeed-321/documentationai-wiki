## REST API Error Responses

Twilio returns standard HTTP status codes with JSON error bodies. Inspect the `code` and `message` fields to identify the root cause.

```json
{
  "code": 20003,
  "message": "Authenticate",
  "more_info": "https://www.twilio.com/docs/errors/20003",
  "status": 401
}
```

## Voice and SIP Trunking Errors

<Expandable title="Error 13214: Invalid 'From' phone number">
Problem: Outbound voice call fails with status 400.

Cause: The `From` parameter contains a number that is not a verified Twilio number or a valid SIP endpoint on the account.

Fix: Replace the value with a number purchased through the Twilio Console or a SIP URI registered under the same account. Example request:

```bash
curl -X POST https://api.example.com/2010-04-01/Accounts/ACxxx/Calls.json \
  -u "ACxxx:your_auth_token" \
  --data-urlencode "From=+15551234567" \
  --data-urlencode "To=+15559876543" \
  --data-urlencode "Url=https://example.com/voice.xml"
```
</Expandable>

<Expandable title="Error 21220: SIP trunk registration failed">
Problem: Inbound calls over a SIP trunk return 503 Service Unavailable.

Cause: The trunk's registration URI or credential list does not match the values configured on the Twilio side.

Fix: Update the trunk registration settings in the Console to match the exact username and password sent by the PBX. Re-register the trunk after the change.

</Expandable>

<Expandable title="Error 32009: No answer from callee">
Problem: Call connects but immediately ends with "no answer".

Cause: The destination answers but sends a SIP 487 or the TwiML `<Dial>` timeout expires before media flows.

Fix: Increase the `timeout` attribute on `<Dial>` or verify that the callee's endpoint accepts early media. Example TwiML:

```xml
<Response>
  <Dial timeout="30">+15559876543</Dial>
</Response>
```
</Expandable>

## Authentication Errors

<Expandable title="Error 20003: Authenticate">
Problem: Every request returns HTTP 401.

Cause: The Account SID or Auth Token supplied in the Authorization header is invalid or has been rotated.

Fix: Retrieve the current Auth Token from the Twilio Console under Account Settings and update the client configuration. Never hard-code tokens in source control.

</Expandable>

## Troubleshooting Failed Requests

When a request fails, capture the full response body and the `X-Twilio-Request-Id` header. Submit both values when opening a support ticket.
