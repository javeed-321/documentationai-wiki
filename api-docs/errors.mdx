## Deployment Failures

<Expandable title="Build Command: `npm run build` exited with 1">
**Problem**

Deployment stops with the exact message:

```text
Build Command: `npm run build` exited with 1
```

**Cause**

The build script fails because a required dependency is missing from `package.json` or an environment variable referenced in the build is undefined.

**Fix**

Add the missing package with `npm install` and commit the updated lockfile. Set any required variables under Project Settings > Environment Variables, then redeploy with `vercel --prod`.
</Expandable>

<Expandable title="The vercel.json file is invalid">
**Problem**

The API returns:

```json
{"error":{"code":"invalid_config","message":"The vercel.json file is invalid"}}
```

**Cause**

A syntax error or unsupported key exists in the root `vercel.json` file.

**Fix**

Validate the file with `vercel build` locally. Remove or correct the invalid key, then push the change.
</Expandable>

## Authentication Errors

<Expandable title="Unauthorized: Invalid token">
**Problem**

Requests to `https://api.example.com/v2/deployments` return status 401 with body:

```json
{"error":{"code":"unauthorized","message":"Invalid token"}}
```

**Cause**

The `Authorization: Bearer` header contains an expired or revoked Vercel token.

**Fix**

Generate a new token at Account Settings > Tokens. Update your CI environment variable `VERCEL_TOKEN` and retry the request.
</Expandable>

## Rate Limiting

<Expandable title="429 Too Many Requests">
**Problem**

The response header includes:

```text
HTTP/2 429
Retry-After: 60
X-RateLimit-Remaining: 0
```

**Cause**

More than 100 requests were sent to the same endpoint within a 60-second window from the same token.

**Fix**

Implement exponential backoff starting at 60 seconds. Cache responses where possible and spread requests across multiple tokens if you require higher limits.
</Expandable>
