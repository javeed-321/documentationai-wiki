## Deployment Failures

Deployment errors occur when a build or deployment request cannot complete successfully.

<Expandable title="DEPLOYMENT_FAILED" default-open="false">

Problem

The API returns status 500 with the following payload:

```json
{
  "error": {
    "code": "DEPLOYMENT_FAILED",
    "message": "Build failed: missing required environment variable"
  }
}
```

Cause

The deployment configuration references an environment variable that is not defined for the target environment.

Fix

Add the missing variable in the project settings or include it in the deployment request body:

```bash
curl -X POST https://api.example.com/v1/deployments \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"env": {"DATABASE_URL": "postgres://..."}}'
```

</Expandable>

## Authentication Errors

Authentication errors are returned when the request lacks valid credentials.

<Expandable title="UNAUTHORIZED" default-open="false">

Problem

Requests without a valid token receive:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or expired access token"
  }
}
```

Cause

The Authorization header contains a token that has been revoked or never existed.

Fix

Generate a new token from the dashboard and include it correctly:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/v1/projects
```

</Expandable>

## Rate Limit Responses

The API enforces rate limits on all endpoints.

<Expandable title="RATE_LIMIT_EXCEEDED" default-open="false">

Problem

After exceeding the limit you receive HTTP 429:

```json
{
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "Too many requests",
    "retryAfter": 60
  }
}
```

Cause

More than 100 requests were sent in a 60-second window from the same token.

Fix

Implement exponential backoff and respect the `retryAfter` value before retrying.

</Expandable>

## Validation Errors

Validation errors indicate malformed request data.

<Expandable title="VALIDATION_ERROR" default-open="false">

Problem

Invalid JSON or missing required fields return:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "name is a required field"
  }
}
```

Cause

The request body does not match the expected schema for the endpoint.

Fix

Validate the payload against the OpenAPI schema before sending and include all required fields.

</Expandable>
