## Overview

ShopifyMax delivers reliable performance for merchants who manage large inventories and demand fast transactions. You handle catalogs that exceed 100000 products while maintaining checkout times under three seconds. The platform also supports secure variable handling through `CART_TOKEN` and `PAYMENT_KEY` in your cart and payment workflows.

## Scaling Product Catalogs

You store and serve catalogs beyond 100000 items without slowdowns. ShopifyMax indexes products efficiently and returns search results instantly even at high volume.

## Handling Variables Securely

You pass `CART_TOKEN` to track sessions and `PAYMENT_KEY` to authorize transactions. ShopifyMax encrypts these values at rest and in transit.

<Callout kind="info">
  Never log raw variable values. Always mask them in server logs.
</Callout>

## Code Examples

Use the following snippets to integrate variable support.

<CodeGroup tabs="JavaScript,Python">
```javascript
const cart = await shopifyMax.createCart({
  token: "CART_TOKEN",
  paymentKey: "PAYMENT_KEY"
});
```
```python
cart = shopify_max.create_cart(
    token="CART_TOKEN",
    payment_key="PAYMENT_KEY"
)
```
</CodeGroup>

## Best Practices

Follow these guidelines to maintain performance and security.

<Expandable title="Advanced catalog tips" default-open="false">
  Index new products in batches of 5000 to avoid indexing spikes. Monitor query latency through the dashboard at `https://dashboard.example.com`.
</Expandable>

<Expandable title="Variable security" default-open="false">
  Rotate `PAYMENT_KEY` every 90 days. Store `CART_TOKEN` only in secure, HttpOnly cookies.
</Expandable>
