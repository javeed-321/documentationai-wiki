## Overview

Vercel delivers a modern deployment platform that streamlines how you build, preview, and ship web applications. Every push to your repository triggers automatic deployments, giving you instant feedback without complex setup. The platform handles infrastructure so you can focus on code.

Core capabilities include preview deployments for every branch, custom domains for production sites, serverless functions for backend logic, and built-in analytics for performance insights.

## Preview Deployments

Preview deployments create isolated environments for every pull request and branch. You receive a unique URL to review changes before merging to production.

## Custom Domains

Connect your own domain to any project. Vercel provisions SSL certificates automatically and routes traffic globally through its edge network.

```bash
vercel domains add example.com
```

Use the dashboard to manage multiple domains and subdomains without leaving your workflow.

## Serverless Functions

Serverless functions run backend code at the edge without managing servers. Write functions in your preferred language and deploy them alongside your frontend.

<CodeGroup tabs="JavaScript,TypeScript">
```javascript
export default function handler(req, res) {
  res.status(200).json({ message: 'Hello from Vercel' });
}
```

```typescript
import type { VercelRequest, VercelResponse } from '@vercel/node';

export default function handler(req: VercelRequest, res: VercelResponse) {
  res.status(200).json({ message: 'Hello from Vercel' });
}
```
</CodeGroup>
