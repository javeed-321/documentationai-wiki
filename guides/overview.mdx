## Overview

Vercel provides a modern deployment platform that handles frontend applications and APIs with minimal configuration. You deploy code from a Git repository and receive automatic previews, production updates, and global distribution. The platform emphasizes performance through edge computing and static optimization.

Core capabilities include serverless functions for backend logic, edge middleware for request handling, monorepo support for complex codebases, and incremental static regeneration for dynamic content.

## Serverless Functions

Serverless functions run on demand without server management. You write standard JavaScript or TypeScript files inside an `api` directory and Vercel deploys them automatically.

```javascript
export default function handler(req, res) {
  res.status(200).json({ message: 'Hello from Vercel' });
}
```

Functions scale automatically and integrate with your frontend routes.

## Edge Middleware

Edge middleware executes at the network edge before requests reach your application. Use it for authentication, redirects, or header modifications with low latency.

Create a `middleware.ts` file at the project root:

```typescript
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  if (request.nextUrl.pathname.startsWith('/admin')) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
  return NextResponse.next();
}
```

<Callout kind="info">
Middleware runs on every request, so keep logic lightweight.
</Callout>

## Incremental Static Regeneration

Incremental static regeneration updates static pages after deployment without rebuilding the entire site. Set a revalidation interval in your page configuration.

```javascript
export async function getStaticProps() {
  const data = await fetchData();
  return {
    props: { data },
    revalidate: 60,
  };
}
```

## Best Practices

- Keep function code under the 50 MB limit for fastest cold starts.
- Use environment variables stored in the dashboard for secrets.
- Test middleware locally with the Vercel CLI before pushing changes.
