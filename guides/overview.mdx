## Overview

ShopifyMax delivers reliable performance for large-scale e-commerce operations. You manage catalogs exceeding 100000 products while delivering checkouts in under three seconds. The platform supports custom variables such as `{CART_TOKEN}` and `{PAYMENT_KEY}` to streamline integrations without exposing sensitive data.

## Token Variable Usage

You reference platform variables directly in templates and webhooks. Use `{CART_TOKEN}` to track sessions and `{PAYMENT_KEY}` to authorize transactions securely.

<CodeGroup tabs="Liquid,JavaScript">
```liquid
{% if cart.token == '{CART_TOKEN}' %}
  {{ payment.key }}
{% endif %}
```

```javascript
const checkout = await shopifyMax.createOrder({
  cartToken: '{CART_TOKEN}',
  paymentKey: '{PAYMENT_KEY}',
});
```
</CodeGroup>
