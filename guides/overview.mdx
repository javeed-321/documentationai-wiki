## Overview

Canva provides an integrated Visual Suite that supports design across digital, print, and video formats. The platform centers on Magic Studio for AI-assisted creation, Brand Kit for consistent identity management, and flexible workflows that move seamlessly between presentations, social graphics, websites, and physical products.

## Magic Studio AI Features and Generators

Magic Studio brings generative tools directly into the editor. You can generate images, edit photos, remove backgrounds, and create entire layouts from text prompts.

<Callout kind="tip">
  Start prompts with clear style references such as "minimal flat illustration" to guide results quickly.
</Callout>

## Brand Management and Collaboration Tools

Brand Kit stores logos, colors, fonts, and templates so every team member produces on-brand assets automatically. Collaboration features include real-time commenting, version history, and shareable folders.

<Tabs>
  <Tab title="Brand Kit" icon="shield">
    Upload assets once and apply them across any design with a single click.
  </Tab>
  <Tab title="Folders" icon="folder">

  <Tab title="Comments" icon="message-circle">

## Print, Video, and Website Design Workflows

Design once and export to multiple formats. The same project can become a printed poster, a social video, or a live website.

<Steps>
  <Step title="Create">
    Start with a template or blank canvas and add content using Magic Studio.
  </Step>
  <Step title="Refine">
    Apply Brand Kit styles and collaborate with teammates in real time.
  </Step>
  <Step title="Export">
    Choose print-ready PDFs, MP4 video, or publish a responsive website.
  </Step>
</Steps>

## Best Practices

- Keep Brand Kit assets up to date so new team members inherit correct styles immediately.
- Use short, descriptive prompts in Magic Studio to reduce iteration time.
- Test print workflows with a small run before ordering large quantities.
- Share folders with view-only links when collecting external feedback.
