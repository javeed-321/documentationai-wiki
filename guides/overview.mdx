## Overview

Stripe provides a complete set of tools to accept payments, manage recurring revenue, power marketplaces, and analyze financial data. You integrate once and unlock online payments, in-person terminals, subscription billing, Connect for platforms, fraud protection via Radar, and deep analytics through Sigma.

## Accepting Payments

Accept payments online or in physical locations with a single integration.

<Tabs>
  <Tab title="Online" icon="globe">
    Use the Payments API to handle card and alternative payment methods in your web or mobile checkout flow.

    Create a payment intent on your server, then confirm it from the client.

    ```javascript
    const paymentIntent = await stripe.paymentIntents.create({
      amount: 2000,
      currency: 'usd',
      automatic_payment_methods: {enabled: true},
    });
    ```

  </Tab>
  <Tab title="In Person" icon="credit-card">
    Pair Stripe Terminal with card readers for retail and hospitality locations. Accept tap, dip, or swipe transactions with the same underlying payment objects.

  </Tab>
</Tabs>

## Analytics and Reporting

Sigma lets you run SQL queries directly against your Stripe data for custom financial reports.

<Expandable title="Example Sigma query" default-open="false">
  Retrieve monthly recurring revenue by product in a single query.

  ```sql
  SELECT
    DATE_TRUNC('month', created) AS month,
    SUM(amount) AS revenue
  FROM charges
  WHERE status = 'succeeded'
  GROUP BY 1
  ORDER BY 1;
  ```

</Expandable>
