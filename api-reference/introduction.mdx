## Welcome

The Twilio REST API lets you integrate SMS, voice, video, and messaging into your applications. Use standard HTTP requests to control communications from any environment.

<Columns cols={2}>
  <Card title="SMS Messaging" icon="message-circle" href="#sms">

  </Card>
  <Card title="Voice Calls" icon="phone" href="#voice">

  </Card>
  <Card title="Video Sessions" icon="video" href="#video">

  </Card>
  <Card title="Core Products" icon="layers" href="#products">

  </Card>
</Columns>

<Card title="Request and Response Format" icon="code" href="/api-reference/voice" horizontal>
  All endpoints accept JSON or form-encoded bodies and return JSON responses with standard status codes.
</Card>

<Card title="Base URLs and Versioning" icon="globe" href="/api-reference/messaging" horizontal>
  Requests target versioned base URLs such as `https://api.example.com/2010-04-01`.
</Card>

<Callout kind="tip">
  Review authentication headers and rate limits before making your first request.
</Callout>
