## Overview

Every request to the Twilio API must include valid credentials. The service supports HTTP Basic Authentication with an Account SID paired with an Auth Token or an API Key. Supply the credentials in the Authorization header for each call.

## Authentication Methods

<Tabs>
  <Tab title="Account SID and Auth Token" icon="key">

Use your Account SID as the username and your Auth Token as the password. These values appear in the Twilio Console.

<ParamField header="Authorization" param-type="string" required="true">
  Basic authentication header containing the Account SID and Auth Token encoded in Base64.
</ParamField>

  </Tab>
  <Tab title="API Keys" icon="key">

Create an API Key in the Twilio Console to obtain a key SID and secret. Use the key SID as the username and the secret as the password.

<ParamField header="Authorization" param-type="string" required="true">
  Basic authentication header containing the API Key SID and secret encoded in Base64.
</ParamField>

  </Tab>
</Tabs>

## Implementation

<CodeGroup tabs="cURL,Python,JavaScript">
```bash
curl -X GET https://api.example.com/2010-04-01/Accounts \
  -u "YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN"
```
```python
import requests
from requests.auth import HTTPBasicAuth

response = requests.get(
    "https://api.example.com/2010-04-01/Accounts",
    auth=HTTPBasicAuth("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")
)
```
```javascript
const response = await fetch("https://api.example.com/2010-04-01/Accounts", {
  headers: {
    Authorization: "Basic " + btoa("YOUR_ACCOUNT_SID:YOUR_AUTH_TOKEN"),
  },
});
```
</CodeGroup>

## Security Tips

<Callout kind="alert">
Store credentials in environment variables or a secure secret manager. Never commit Account SIDs, Auth Tokens, or API Key secrets to source control. Rotate tokens regularly and limit their scope to the minimum required permissions.
</Callout>
