## Prerequisites

<Callout kind="info">
Obtain a Twilio account and phone number before running any code examples.
</Callout>

## Obtain a phone number

Follow these steps to acquire a number capable of sending SMS and making voice calls.

<Steps>
  <Step title="Sign up" icon="user">
    Create an account at the Twilio console and verify your email address.
  </Step>
  <Step title="Buy a number" icon="phone">
    Search for and purchase a number from the available inventory. Note the number for later use.
  </Step>
  <Step title="Retrieve credentials" icon="key">
    Copy your Account SID and Auth Token from the dashboard. Store them securely.
  </Step>
</Steps>

## Send an SMS message

Use the following example to send a text message from your Twilio number.

<CodeGroup tabs="Node.js,Python">
```javascript
const twilio = require("twilio");
const client = twilio("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN");

client.messages
  .create({
    body: "Hello from Twilio",
    from: "+15005550006",
    to: "+15005550006",
  })
  .then((message) => console.log(message.sid));
```
```python
from twilio.rest import Client

client = Client("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")

message = client.messages.create(
    body="Hello from Twilio",
    from_="+15005550006",
    to="+15005550006",
)
print(message.sid)
```
</CodeGroup>

## Make an outbound voice call

Use the following example to initiate a voice call that plays a simple message.

<CodeGroup tabs="Node.js,Python">
```javascript
const twilio = require("twilio");
const client = twilio("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN");

client.calls
  .create({
    url: "https://api.example.com/voice.xml",
    from: "+15005550006",
    to: "+15005550006",
  })
  .then((call) => console.log(call.sid));
```
```python
from twilio.rest import Client

client = Client("YOUR_ACCOUNT_SID", "YOUR_AUTH_TOKEN")

call = client.calls.create(
    url="https://api.example.com/voice.xml",
    from_="+15005550006",
    to="+15005550006",
)
print(call.sid)
```
</CodeGroup>
